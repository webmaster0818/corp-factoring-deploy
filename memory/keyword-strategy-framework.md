# キーワード戦略フレームワーク

## 検索意図の基礎知識(鈴木謙一ブログより)

### 3つの基本分類

**1. 取引型(Transactional/Do)**
- ユーザー意図: 何かをしたい、購入したい、アクションを起こしたい
- 特徴: CVRが一般的に高い
- 例: 「iPhone5ケース 通販」「Google Chrome ダウンロード」「リフォーム 資料請求」

**2. 情報収集型(Informational/Know)**
- ユーザー意図: 何かを知りたい、疑問や悩みを解決したい
- 特徴: 検索ボリュームが多い、ロングテールSEOに向いている、リード獲得に有効
- 例: 「ネクタイ 結び方」「カルボナーラ レシピ」「ふくらはぎ むくみ解消」

**3. 案内型(Navigational/Go)**
- ユーザー意図: 特定のサイト・ページにアクセスしたい
- 特徴: サイトリンクが出ることが多い
- 例: 「ウィキペディア」「楽天市場」「Facebook ログイン」

**4. ローカル型(Local)**
- ユーザー意図: 位置情報・場所に関連した情報を探している
- 特徴: 明示的(「渋谷 カフェ」)または暗黙的(「スターバックス」)
- 例: 「近くのスターバックス」「渋谷 マクドナルド」

### 重要なポイント

**複数の意図を持つクエリ:**
- 「iPhone5」= 案内型 + 情報収集型 + 取引型
- 「Google Chrome ダウンロード」= 案内型 + 取引型

**検索意図のサイクル:**
- ユーザーは情報収集型 → 情報収集型(比較) → 取引型 → 案内型とサイクルする
- 例: 「Canon デジタルカメラ」→「PowerShot G1 X 評価」→「PowerShot G1 X 通販」→「Amazon PowerShot G1 X」

## 戦略的キーワード優先順位の決定

### 優先順位の判断基準

**3つの軸で評価:**
1. **検索ボリューム** - どれだけ検索されているか
2. **CVR(コンバージョン率)** - どれだけ成約につながるか
3. **競合状況** - 上位表示の難易度

### BEST-FITの戦略的優先順位

**最優先(S): ③エリア×パーソナルジム×条件**
```
理由:
✅ CVRが高い(15-20%)
✅ 購入意向が明確
✅ 検索ボリュームも十分
✅ ポータルサイトが強い領域
✅ ジム公式サイトより有利

具体例:
- 渋谷 パーソナルジム 安い
- 渋谷 パーソナルジム 女性
- 渋谷 パーソナルジム 短期

推奨ページ: エリア記事内の「こだわり別セクション」
```

**高優先(A): ②エリア×パーソナルジム**
```
理由:
✅ 検索ボリュームが大きい
✅ CVRも中程度(10-15%)
✅ ポータルサイトが強い領域
✅ 最もトラフィックを獲得できる

具体例:
- 渋谷 パーソナルジム
- 新宿 パーソナルジム
- 池袋 パーソナルジム

推奨ページ: エリア記事(メインコンテンツ)
```

**高優先(A): ⑤ジム名×口コミ・料金**
```
理由:
✅ CVRが非常に高い(20-30%)
✅ 購入直前の最終確認段階
✅ ポータルサイトが有利(公式より中立的な情報を求める)
✅ ロングテール戦略に最適

具体例:
- ライザップ 口コミ
- ライザップ 料金
- 24/7ワークアウト 評判

推奨ページ: ジム詳細ページ(ただしカニバリ注意)
```

**中優先(B): ①パーソナルジム単ワード・比較・おすすめ**
```
理由:
✅ 検索ボリュームが非常に大きい
❌ CVRは低い(5-10%)
❌ 競合が強い(大手メディアが多い)
⚠️ ブランディング目的で重要

具体例:
- パーソナルジム おすすめ
- パーソナルジム 比較
- パーソナルジム ランキング

推奨ページ: トップページ or 全国版記事
```

**中優先(B): ④ジム名、ブランド名**
```
理由:
✅ CVRは中〜高(15-25%)
❌ ジム公式サイトが強い
❌ ポータルサイトには不利

具体例:
- ライザップ
- 24/7ワークアウト
- エクササイズコーチ

推奨ページ: ジム詳細ページ
戦略: 「ライザップ 口コミ」など複合キーワードで流入を狙う
```

**低優先(C): ⑥ジム名×エリア**
```
理由:
✅ CVRは最高(30-40%)
❌ ジム公式サイトが圧倒的に強い
❌ ポータルサイトには極めて不利
❌ 検索ボリュームも小さい

具体例:
- ライザップ 渋谷
- 24/7ワークアウト 新宿

推奨ページ: ジム詳細ページ(エリア情報含む)
戦略: 無理に狙わず、エリア記事からの内部リンクで補完
```

### どのページでどのキーワードを取るべきか

## まとめ: キーワード戦略の思考プロセス

### STEP1: キーワードを分類する

```
検索意図で分類:
- 取引型(Do) → CVR高い
- 情報収集型(Know) → ボリューム大きい
- 案内型(Go) → サイトリンク
- ローカル型(Local) → エリア限定

カスタマージャーニーで分類:
- 認知段階 → ①パーソナルジム おすすめ
- 比較検討初期 → ②エリア×パーソナルジム
- 比較検討後期 → ③エリア×パーソナルジム×条件
- 特定ジム調査 → ④ジム名
- 購入直前 → ⑤ジム名×口コミ
- 購入 → ⑥ジム名×エリア
```

### STEP2: 優先度を決める

```
3つの軸で評価:
1. 検索ボリューム
2. CVR
3. 競合状況(ポータルサイトが有利か?)

BEST-FITの優先順位:
S級: ③エリア×パーソナルジム×条件
A級: ②エリア×パーソナルジム、⑤ジム名×口コミ・料金
B級: ①パーソナルジム単ワード、④ジム名
C級: ⑥ジム名×エリア
```

### STEP3: どのページで取るか決める

```
ページタイプとキーワードのマッピング:
- トップページ → ①パーソナルジム おすすめ
- エリア記事 → ②③エリア×パーソナルジム(×条件)
- ジム詳細ページ → ④⑤⑥ジム名系(ただしカニバリ注意)
- ブログ記事 → 情報収集型(選び方、効果など)

カニバリ回避:
⚠️ ジム詳細ページはnoindex化
⚠️ または、pas0na.com型(詳細ページなし)
```

### STEP4: 新規作成の順序を決める

```
Phase 1(最優先):
1. エリア記事(主要エリアから)
2. トップページ最適化

Phase 2(中優先):
3. ブログ記事(ノウハウ系)

Phase 3(検討):
4. ジム詳細ページ(作成するならnoindex)
5. 動的一覧ページ(作成非推奨)
```

### STEP5: SEO構成とCVR最適化を統合

```
SEO観点:
✅ 検索意図の徹底網羅(1ページで複数キーワード)
✅ 情報の具体性(4テーブル構造)
✅ 内部リンク戦略(滞在時間延長)
✅ E-E-A-T強化(監修者情報)
✅ フレッシュネス(更新日明示)
✅ 構造化データ(FAQ, Article, Author)

CVR観点:
✅ ファーストビューの最適化(即座にニーズを満たす)
✅ 比較しやすさ(テーブル、カード型レイアウト)
✅ CTAの最適配置(6箇所以上)
✅ 不安解消(FAQ、口コミ)
✅ 信頼性向上(監修者、更新日、具体的数値)
✅ 選びやすさ(条件絞り込み、ソート機能)
```
