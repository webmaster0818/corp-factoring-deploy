### CSS修正の試行錯誤

**時系列：**
1. **00:07** - コミット 07283bc: `text-base-content/80` → `text-gray-900`（濃いグレー）に変更
2. **00:15** - コミット 1ecb538: ダークモード無効化 + `!important` でテキスト色を強制
   - 問題: `.bg-white` セレクタが広範囲すぎて、比較表の暗い背景にも黒テキストが適用された
   - 結果: 黒背景に黒テキストで読めなくなった
3. **00:42** - コミット d455dc3: セレクタを `.bg-white.shadow-lg` に限定
   - 個別業者紹介セクション（白背景）のみにテキスト色強制を適用
   - 比較表は通常のスタイルに戻る

**根本原因：**
- モバイルブラウザが `@media (prefers-color-scheme: dark)` を優先
- `--foreground: #ededed`（薄いグレー）が適用される
- Tailwind CSSの `text-gray-900` や `text-black` が無視される

**最終解決策：**
```css
/* 個別業者紹介セクションのみにテキスト色強制を適用 */
.bg-white.shadow-lg h3,
.bg-white.shadow-lg h4,
.bg-white.shadow-lg li,
.bg-white.shadow-lg p {
  color: #000000 !important;
}
```

### 学んだこと

**CSSのセレクタ設計：**
- `.bg-white` は広範囲すぎる（比較表、業者紹介セクション、その他の白背景すべてに適用される）
- `.bg-white.shadow-lg` に限定することで、個別業者紹介セクションのみに適用できる
- 暗い背景のセクションには通常のスタイルが適用される
