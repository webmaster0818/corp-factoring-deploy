# Getfit オーガニック流入激減の要因分析

## 📉 調査概要

**調査対象:** https://getfit.jp/
**調査期間:** 2026年3月3日
**調査目的:** 昨年末(2025年12月頃)からオーガニック流入が激減している要因の特定

---

## 🔍 発見された重大な問題

### 1️⃣ **大量の404エラー(最重要)**

**確認された404ページ:**
- ❌ `https://getfit.jp/sitemap.xml` → **404エラー**
- ❌ `https://getfit.jp/personal_gym-tokyo-shibuya` → **404エラー**
- ❌ `https://getfit.jp/personal_gym-shibuya` → **404エラー**

**影響:**
```
旧URL構造 → 新URL構造への移行が不完全
↓
被リンク・既存インデックスが404エラー
↓
Googleからの評価が急落
↓
オーガニック流入激減
```

**404ページのメッセージ:**
> 「あなたがアクセスしようとしたページは削除されたかURLが変更されています」

**重大性:** ⭐⭐⭐⭐⭐
- SEOにおいて404エラーは致命的
- 特にサイトマップが404なのは深刻
- 被リンク効果が完全に失われている

---

### 2️⃣ **sitemap.xml が存在しない**

**問題点:**
- `robots.txt` に sitemap の記載がない
- `sitemap.xml` にアクセスすると404

**比較: pas0na.com**
```
# pas0na.com の robots.txt
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php

Sitemap: https://pas0na.com/sitemap.xml  ← ✅ 明記
Sitemap: https://pas0na.com/sitemap.html
```

**Getfitの robots.txt**
```
User-agent: *
Disallow: /wp-admin/
Allow: /wp-admin/admin-ajax.php
                                          ← ❌ Sitemapの記載なし
```

**影響:**
- Googleがページを発見できない
- インデックスされない
- クロール効率が大幅に低下

**重大性:** ⭐⭐⭐⭐⭐

---

### 3️⃣ **URL構造の変更(リダイレクト未設定)**

**推測される変更:**

**旧URL構造(2025年以前):**
```
/personal_gym-tokyo-shibuya
/personal_gym-osaka-umeda
/personal_gym-{都道府県}-{エリア}
```

**新URL構造(2026年?):**
```
不明 (JavaScript依存の可能性)
```

**問題:**
- 301リダイレクトが設定されていない
- 既存の被リンクがすべて404
- Googleにインデックスされていたページが消失
- PageRankの引き継ぎなし

**影響:**
```
被リンク効果: 100% → 0%
インデックス数: 大幅減少
ドメインオーソリティ: 急落
↓
オーガニック流入激減
```

**重大性:** ⭐⭐⭐⭐⭐

---

### 4️⃣ **JavaScript依存の可能性**

**トップページの分析:**
- web_fetchで取得できた内容が非常に薄い(3,000文字程度)
- 口コミコンテンツのみ
- 地域リンクが正常に機能していない可能性

**比較: pas0na.com**
- web_fetchで16,000文字超の詳細コンテンツ取得可能
- クローラーが読み取れる静的HTML

**推測:**
- サイトリニューアルでSPA(Single Page Application)化?
- クライアントサイドレンダリング(CSR)に変更?
- JavaScript無効環境でコンテンツが表示されない?

**SEOへの影響:**
- Googleクローラーが十分にコンテンツを読み取れない
- インデックスされるコンテンツが激減
- 検索順位が大幅に下落

**重大性:** ⭐⭐⭐⭐

---

### 5️⃣ **コンテンツの薄さ(トップページ)**

**Getfitトップページ:**
- 取得できた文字数: 約3,000文字
- 内容: 口コミ8件のみ
- 構造化されたコンテンツなし

**pas0na.com 渋谷ページ(比較):**
- 文字数: 16,000文字超
- 内容: ジム11選 + 料金相場 + 選び方 + FAQ10問
- 超網羅的

**問題:**
- Googleが評価するコンテンツ量が不足
- UGCに依存しすぎ
- 独自コンテンツが少ない

**重大性:** ⭐⭐⭐

## 💡 Getfit流入激減の主要因(結論)

### 🔥 最重要要因(TOP3)

**1位: 大量の404エラー(重大度: ⭐⭐⭐⭐⭐)**
- URL構造変更時の301リダイレクト未設定
- 既存の被リンク・インデックスがすべて404
- PageRankの引き継ぎゼロ

**2位: sitemap.xml の消失(重大度: ⭐⭐⭐⭐⭐)**
- Googleが新しいページを発見できない
- クロール効率が大幅に低下
- インデックス数の減少

**3位: JavaScript依存度の上昇(重大度: ⭐⭐⭐⭐)**
- クローラーがコンテンツを読み取れない
- インデックスされるコンテンツが激減
- 検索順位の大幅下落

### 🎯 補助的要因

**4位: コンテンツの薄さ(重大度: ⭐⭐⭐)**
- pas0na.comと比較してコンテンツ量が不足
- UGC依存でGoogleが評価する独自コンテンツ少ない

**5位: E-E-A-T要素の弱さ(重大度: ⭐⭐)**
- 監修者情報が不明確
- 運営ポリシーへのリンクあり(but 404?)
- 更新日の表示なし

## 🚨 緊急度評価

### 🔴 即座に対応すべき(Critical)

1. **301リダイレクト設定**
   - 旧URL → 新URL へのリダイレクト
   - すべての404ページを確認し、適切なリダイレクト設定

2. **sitemap.xml の復旧**
   - sitemap.xmlを生成
   - robots.txtに記載
   - Google Search Consoleに送信

3. **404エラーの一括修正**
   - サイト内の内部リンクを新URL構造に修正
   - 外部からの被リンクを調査し、可能なら更新依頼

### 🟡 早急に対応すべき(High)

4. **JavaScript SEO対策**
   - サーバーサイドレンダリング(SSR)導入
   - 動的レンダリング(Dynamic Rendering)
   - プリレンダリング

5. **コンテンツの強化**
   - 地域ページに独自コンテンツ追加
   - 料金相場、選び方、FAQ追加
   - pas0na.com並みの網羅性を目指す

### 🟢 中期的に対応すべき(Medium)

6. **E-E-A-T要素の強化**
   - 監修者情報の明記
   - 更新日の表示
   - 運営ポリシーの整備

7. **テクニカルSEO監査**
   - Core Web Vitals改善
   - ページスピード最適化
   - 構造化データ実装

4. **段階的移行**
   - 全ページを一度に変更しない
   - 主要ページから段階的に
   - 影響を監視しながら進める

5. **JavaScript SEO対策**
   - SPAにする場合はSSR必須
   - クローラーテスト必須
   - Fetch as Googleで確認

## 🎯 総括

### Getfit流入激減の本質

**「サイトリニューアル時のSEO基本対応の失敗」**

具体的には:
1. 301リダイレクト未設定 → 被リンク効果消失
2. sitemap.xml消失 → クロール不可
3. JavaScript依存度上昇 → インデックス減少

**回復可能性:** ✅ 高い
**条件:** 上記3点を早急に対応すれば2-3ヶ月で回復可能

**放置した場合:** ❌ さらに悪化し、競合にシェアを奪われ続ける
