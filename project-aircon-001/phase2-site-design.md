## 2. 主要ページの設計

### 2-1. トップページ（/）

#### 目的
- 初訪問ユーザーにサイトの価値を即座に伝える
- 主要コンテンツへのスムーズな導線を作る
- SEO対策（「エアコンクリーニング 比較」で上位表示）

#### コンテンツ構成

1. **ファーストビュー**
   - キャッチコピー: 「エアコンクリーニング業者を徹底比較！あなたにピッタリの業者が見つかる」
   - サブコピー: 「料金・口コミ・地域で簡単検索 | 最新キャンペーン情報も毎日更新」
   - CTA: 「おすすめ業者ランキングを見る」ボタン（目立つ配色）
   - 検索ボックス: 「お住まいの地域を入力」→地域別ページへ誘導

2. **おすすめ業者TOP3**
   - カード型デザイン
   - 各業者の特徴を3行で要約
   - 料金（1台あたり）を大きく表示
   - 「詳細を見る」ボタン
   - キャンペーン情報バッジ（「今だけ1,100円OFF!」など）

3. **3つの特徴（なぜ当サイトを選ぶべきか）**
   - ✅ 15社以上の業者を徹底比較
   - ✅ 毎日更新される最新キャンペーン情報
   - ✅ 実際に利用した人の口コミ多数掲載

4. **タイプ別おすすめ業者**
   - タブ切り替え式
   - 「とにかく安く」「大手で安心」「土日対応」「複数台割引」の4タブ
   - 各タブに2〜3社を表示

5. **料金相場表**
   - 壁掛け・お掃除機能付き・天井埋込の3種類
   - 1台・2台・3台の料金を比較表で表示

6. **地域別検索セクション**
   - 日本地図 or 都道府県リンク一覧
   - 「お住まいの地域を選んでください」

7. **最新キャンペーン情報**
   - 新着3件を表示
   - 「もっと見る」で一覧ページへ

8. **よくある質問（FAQ）**
   - アコーディオン式で5〜7個を表示
   - 「エアコンクリーニングの頻度は？」「料金相場は？」など

### 2-2. ランキングページ (/ranking/)

#### 総合ランキング (/ranking/overall/)

**評価基準（5項目）**
- 料金の安さ（30%）
- 口コミ評価（25%）
- 技術力・品質（20%）
- 予約のしやすさ（15%）
- キャンペーン・割引（10%）

**表示形式**
1. 各業者をカード形式で表示
2. 総合スコア（5点満点）をグラフ表示
3. 各評価項目を星5段階で表示
4. メリット・デメリットを箇条書き
5. 料金表（1台・2台・お掃除機能付き）
6. 最新キャンペーン情報
7. 公式サイトへのCTAボタン（アフィリエイトリンク）

---

### 2-3. 地域別ページ (/area/)

#### 例: 東京都ページ (/area/tokyo/)

**コンテンツ構成**
1. **タイトル**: 「東京都でおすすめのエアコンクリーニング業者ランキング」
2. **リード文**: 東京都の特徴（エアコン設置率、平均利用頻度など）
3. **東京都対応の業者ランキング（TOP5）**
   - 各業者の東京都内の店舗数・対応エリアを明記
   - 東京都限定キャンペーンがあれば強調
4. **東京都の料金相場**
   - 東京都の平均料金と全国平均を比較
5. **東京都でよくある質問**
   - 「23区内は駐車場代がかかる？」など地域特有のQ&A
6. **東京都の区市町村別リンク**
   - 「新宿区」「渋谷区」「世田谷区」など主要区へのリンク

## 4. 技術選定

### 4-1. フレームワーク・CMS

**推奨: Next.js（静的サイト生成）**

**理由**
- SEOに強い（SSG/SSRでページ速度が速い）
- Reactベースで柔軟なUIが作れる
- Vercel/Cloudflare Pagesで無料ホスティング可能
- 更新も簡単（MDXでコンテンツ管理）

**代替案: WordPress**
- メリット: ノーコードで更新可能、プラグイン豊富
- デメリット: 速度がNext.jsより遅い、セキュリティリスク

---

### 4-2. 技術スタック

```
フロントエンド:
- Next.js 14（App Router）
- TypeScript
- Tailwind CSS
- shadcn/ui（UIコンポーネント）

コンテンツ管理:
- MDX（記事コンテンツ）
- JSON（業者データ、料金情報）

デプロイ:
- Vercel or Cloudflare Pages

分析:
- Google Analytics 4
- Google Search Console

アフィリエイトトラッキング:
- ASPのトラッキングタグ
```
