### Phase 3: アラート&インサイト分析
**実装日:** 2026/3/13 18:45

✅ **アラートシステム** (`alert-system.js`)

**順位変動アラート:**
- 5位以上下落 → 警告
- 10位以上下落 → 重大アラート
- 5位以上上昇 → ポジティブアラート

**トラフィック異常検知:**
- 前週比20%減 → セッション数アラート
- 前週比20%減 → ユーザー数警告
- 前週比50%増 → ポジティブアラート

**パフォーマンス低下:**
- Search Consoleクリック数30%減 → 重大アラート
- 平均CTR 25%減 → 警告

✅ **インサイト分析** (`insights-analyzer.js`)

**キーワード機会分析:**
- 順位4-20位のクエリ抽出（少し改善で1ページ目入り）
- 表示回数10以上が条件
- 潜在クリック数を計算
- 実績: K-ETA 15件、ETIAS 11件のキーワード機会検出

**CTR改善提案:**
- 上位表示（10位以内）でCTR3%未満のクエリ
- 表示回数50以上が条件
- 期待CTRとの比較
- 潜在クリック数を算出

**トラフィックトレンド:**
- 週内の前半・後半比較
- 10%以上の変動を検出
- 実績: K-ETA +34.1%上昇、UK-ETA +184.6%上昇

**ページパフォーマンス:**
- 表示100以上、CTR2%未満のページ抽出
- 改善優先度の高いページ特定
- 実績: K-ETA 3ページ、ETIAS 3ページ検出
