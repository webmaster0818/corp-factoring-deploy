# 📊 データエクスポート手順（5分で完了）

## 🔍 Search Console データ

### 手順：

1. **Search Console にアクセス**  
   https://search.google.com/search-console?resource=https://keta-travel.com

2. **パフォーマンスレポート**
   - 左メニュー → **パフォーマンス**
   - 期間設定: **2025年1月1日 〜 2026年3月13日**（カスタム）

3. **データをエクスポート**
   
   **A. クエリ別データ（必須）**
   - タブで **クエリ** を選択
   - 右上の **エクスポート** → **Google スプレッドシートにエクスポート** または **CSVをダウンロード**
   - ファイル名: `sc_queries.csv`
   
   **B. ページ別データ（必須）**
   - タブで **ページ** を選択
   - エクスポート → `sc_pages.csv`
   
   **C. 日別データ（重要）**
   - タブで **日付** を選択
   - エクスポート → `sc_daily.csv`
   
   **D. デバイス別データ（参考）**
   - タブで **デバイス** を選択
   - エクスポート → `sc_devices.csv`

## 📊 Google Analytics 4 データ

### 手順：

1. **GA4 にアクセス**  
   https://analytics.google.com/

2. **探索レポート作成**
   - 左メニュー → **探索**
   - **空白** を選択

3. **ディメンションと指標を追加**
   
   **セグメント:**
   - 期間: 2025年1月1日 〜 2026年3月13日
   
   **ディメンション（左側に追加）:**
   - 日付
   - ページパスとスクリーンクラス
   - 参照元 / メディア
   - デバイスカテゴリ
   
   **指標（右側に追加）:**
   - セッション
   - ユーザー
   - 新しいユーザー
   - 表示回数
   - エンゲージメント率
   - 直帰率
   - 平均エンゲージメント時間

4. **レポートを作成**
   
   **A. 日別トラフィック（必須）**
   - 行: 日付
   - 値: セッション、ユーザー、表示回数、直帰率
   - エクスポート → `ga4_daily.csv`
   
   **B. ページ別パフォーマンス（必須）**
   - 行: ページパスとスクリーンクラス
   - 値: 表示回数、セッション、ユーザー、直帰率
   - ソート: 表示回数（降順）
   - エクスポート → `ga4_pages.csv`
   
   **C. トラフィックソース（重要）**
   - 行: 参照元 / メディア
   - 値: セッション、ユーザー、新しいユーザー
   - ソート: セッション（降順）
   - エクスポート → `ga4_sources.csv`
