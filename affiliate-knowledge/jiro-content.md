## 1. 業界別コンテンツパターン（5業界）

### 1.1 美容・化粧品業界

#### 法規制の特徴
**薬機法（医薬品医療機器等法）が最重要**
- 効果効能の表現に厳しい制限
- Before/After表現に注意が必要
- 医師・専門家監修が推奨

#### NG表現例
❌ 「シミが消える」「ニキビが治る」「若返る」
❌ 「医学的に証明された」「確実に効果がある」
❌ 「たった7日で-5歳肌」

#### OK表現例
✅ 「ハリ・ツヤのある印象へ」「明るい印象の肌」
✅ 「うるおいを与える」「乾燥を防ぐ」
✅ 「使用者の90%が満足と回答」（アンケート結果として）

#### コンテンツテンプレート

**記事タイトル例:**
- 「【2026年最新】30代向け美容液おすすめ15選｜選び方のポイントも解説」
- 「敏感肌でも使える化粧水10選｜皮膚科医監修で安心」

**記事構成（3,000文字）:**
```
1. 導入（300文字）
   - 読者の悩み共感
   - この記事で分かること明示

2. 選び方のポイント（600文字）
   - 成分の見方
   - 肌質別の選び方
   - 価格帯の考え方

3. おすすめ商品ランキング（1,500文字）
   - 各商品の特徴
   - おすすめポイント
   - 価格・内容量
   - 【監修者コメント】付き

4. よくある質問（Q&A）（400文字）
   - 使用方法
   - 副作用・注意点

5. まとめ（200文字）
   - 選び方の再確認
   - アフィリエイトリンク誘導
```

#### E-E-A-T強化ポイント
- **監修者:** 皮膚科医、美容皮膚科専門医
- **引用:** 成分データベース（INCI、厚労省資料）
- **体験談:** 実際の使用レビュー（薬機法遵守）

✅ 「審査が比較的柔軟」「主婦・学生も申込可能」
✅ 「当サイト調べで人気No.1」（根拠明示）
✅ 「金利○%〜○%（審査により決定）」

#### コンテンツテンプレート

**記事タイトル例:**
- 「【2026年版】年会費無料クレジットカード比較｜ポイント還元率で選ぶおすすめ10枚」

**記事構成（3,500文字）:**
```
1. 導入（300文字）
   - ニーズ確認（年会費無料、高還元率など）

2. 選び方の基準（700文字）

   - 年会費

3. 比較表（800文字）

   - メリット・デメリット

   - 返済計画の重要性
```

## 1. 2024-2026年のSEOトレンド

### 1.2 SGE（Search Generative Experience）対策

**SGEとは:**

## 5. 一次情報の重要性

### 5.1 Googleが求める一次情報

**定義:**
- 自分で体験・調査・取材したオリジナル情報

```
❌ 公式サイトの情報をコピペ

```

### 4.2 自動化スクリプトの実装例

**Python スクリプト例（概念）:**

```python
import requests
import pandas as pd

# 1. シードキーワードリスト
seed_keywords = [
    "パーソナルジム",
    "美容液",
    "クレジットカード",
    # ...
]

# 2. ラッコキーワードAPIで関連キーワード取得
def get_related_keywords(seed):
    url = f"https://api.rakko-tools.com/keyword?seed={seed}"
    response = requests.get(url, headers={"API-Key": "YOUR_API_KEY"})
    return response.json()["keywords"]

# 3. 検索ボリューム取得（Ahrefs API）
def get_search_volume(keyword):
    url = f"https://api.ahrefs.com/v3/keywords?keyword={keyword}"
    response = requests.get(url, headers={"Authorization": "Bearer YOUR_TOKEN"})
    return response.json()["search_volume"]

# 4. 全キーワードを処理
results = []
for seed in seed_keywords:
    related = get_related_keywords(seed)
    for kw in related:
        volume = get_search_volume(kw)
        results.append({
            "keyword": kw,
            "volume": volume,
            "difficulty": "中",  # 実際にはAPI取得
        })

# 5. CSV出力
df = pd.DataFrame(results)
df.to_csv("keywords.csv", index=False)
```

```
パーソナルジム 東京,1200,中
パーソナルジム 女性専用,480,低
パーソナルジム 料金,820,中
...
```
