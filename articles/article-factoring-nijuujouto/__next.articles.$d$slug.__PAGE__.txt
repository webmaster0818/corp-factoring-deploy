4:T2e16,<p>同じ売掛金を2社に売却した場合どうなるか、資金に困っているため知られなければ問題ないのではないか、といった考えは<strong>認められません</strong>。二重譲渡は民事上の責任に加え、**刑事罰（詐欺罪・横領罪）**の対象となり、法人・個人事業のいずれにも重大な影響を及ぼします。</p>
<p>この記事では、ファクタリングの二重譲渡が成立する仕組み、法的な罪状、ファクタリング会社による検知の方法、発覚した場合の対処法を解説します。</p>
<hr>
<h2>二重譲渡の定義と典型例</h2>
<p><strong>二重譲渡</strong>：同一の売掛債権を、異なる複数のファクタリング会社・債権者に重複して譲渡する行為です。</p>
<h3>典型例</h3>
<ol>
<li>売掛金100万円をA社にファクタリングで売却する</li>
<li>その後、同じ売掛金をB社にもファクタリングで売却する</li>
<li>売掛先から100万円が入金されると、A社・B社の両方が回収の権利を主張する</li>
</ol>
<p>これは<strong>法的に成立し得ない取引</strong>であり、明白な犯罪です。</p>
<hr>
<h2>二重譲渡の法的な罪状</h2>
<h3>1. 詐欺罪（刑法246条）</h3>
<ul>
<li>法定刑：10年以下の懲役</li>
<li>すでに他社に譲渡済みの債権を「未譲渡」と偽って契約 → 詐欺</li>
<li>ファクタリング会社が誤って買い取る → 損害が確定</li>
</ul>
<h3>2. 横領罪（刑法252条）</h3>
<ul>
<li>法定刑：5年以下の懲役</li>
<li>入金された100万円のうち、最初の譲渡先（A社）に渡すべき分を、別の会社（B社）に渡す → 業務上横領</li>
</ul>
<h3>3. 背任罪（刑法247条）</h3>
<ul>
<li>法定刑：5年以下の懲役または50万円以下の罰金</li>
<li>経営者として、会社の利益に反する取引を行う → 背任</li>
</ul>
<h3>4. 民事上の責任</h3>
<ul>
<li>損害賠償請求</li>
<li>遅延損害金</li>
<li>弁護士費用の負担</li>
<li>信用の失墜による取引の停止</li>
</ul>
<p>刑事と民事の両面で責任を問われます。</p>
<hr>
<h2>二重譲渡が起きる理由</h2>
<h3>パターン1：資金繰りの悪化による誘惑</h3>
<p>急ぎの資金需要から、「もう1社に売却すればよい」と短絡的に判断してしまうケースです。</p>
<h3>パターン2:違法業者からの勧誘</h3>
<p><a href="/articles/article-factoring-ihou-gyousha/">違法業者</a>が「他社には知られない」「審査に通る」と誘導するケースです。</p>
<h3>パターン3：管理上のミス</h3>
<p>複数の売掛金を持つ企業が、どの売掛金をすでに譲渡したかを管理できていないケースです。</p>
<h3>パターン4:意図的な詐欺行為</h3>
<p>最初から複数社に売却する計画で、書類を偽造する悪質なケースです。</p>
<p>いずれのパターンでも、結果として刑事罰の対象となります。</p>
<hr>
<h2>ファクタリング会社による検知の方法</h2>
<h3>1. 債権譲渡登記の確認</h3>
<p>ファクタリング会社の多くは、<strong>債権譲渡登記ファイル</strong>を照会します。すでに登記されていれば、すぐに発覚します。</p>
<h3>2. 売掛先への直接の確認（3社間の場合）</h3>
<p>3社間ファクタリングでは売掛先に通知するため、すでに他社が通知していれば判明します。</p>
<h3>3. 会社間の情報共有</h3>
<p>業界団体に加盟しているファクタリング会社の間で、ブラックリスト・利用履歴の情報交換が行われています。</p>
<h3>4. 入金履歴の照合</h3>
<p>売掛先から入金された場合、口座・金額・時期の観点から、すでに他社に支払われていないかを確認します。</p>
<h3>5. AI審査による異常の検知</h3>
<p>近年は、<a href="/articles/article-factoring-ai-shinsa/">AI審査ファクタリング</a>が、過去の譲渡のパターン・申込履歴から、機械学習により異常を検知します。</p>
<hr>
<h2>二重譲渡を防ぐための実務上の対策</h2>
<h3>利用者の場合</h3>
<h4>✅ 譲渡済みの売掛金のリストを管理する</h4>
<p>スプレッドシートに、「売掛先・金額・譲渡先・譲渡日」を必ず記録してください。</p>
<h4>✅ ファクタリング会社を1社に絞る</h4>
<p>複数社を利用する場合は、<a href="/articles/article-factoring-fukusu/">複数ファクタリングの併用</a>の記事をご覧いただいたうえで、譲渡の対象を明確に区分してください。</p>
<h4>✅ 契約時のチェックリストの確認</h4>
<p>申込時の「この売掛金は他社に譲渡していますか」という質問には、事実どおりに回答してください。</p>
<h4>✅ 顧問税理士・弁護士への相談</h4>
<p>複雑な売掛債権がある場合は、専門家の確認を受けてください。</p>
<hr>
<h2>二重譲渡における優先順位の法的なルール</h2>
<p>万一、二重譲渡が発生した場合の、債権者間の優先順位の決まり方は以下のとおりです。</p>
<h3>民法467条：対抗要件</h3>
<ul>
<li><strong>第三者対抗要件</strong>：確定日付のある通知または承諾（売掛先への通知）</li>
<li><strong>債務者対抗要件</strong>:売掛先への通知</li>
</ul>
<h3>優先順位の決まり方</h3>
<ol>
<li><strong>登記の有無</strong>：<a href="/articles/article-factoring-saiken-touki/">債権譲渡登記</a>がある場合は、ない場合より優先</li>
<li><strong>登記がない場合</strong>：確定日付の早いほうが優先</li>
<li><strong>同じ日付の場合</strong>：売掛先に先に到達したほうが優先</li>
</ol>
<p>後から譲渡を受けたファクタリング会社が、登記または確定日付を先に取得した場合、最初の譲渡先が劣後する可能性もあります。</p>
<p>→ ファクタリング会社が登記を急ぐのは、このためです。</p>
<hr>
<h2>二重譲渡の事例</h2>
<h3>事例1:都内中小企業の経営者(2020年)</h3>
<ul>
<li>売掛金300万円を、3社に重複して譲渡</li>
<li>詐欺罪で起訴され、懲役2年6ヶ月（執行猶予4年）</li>
<li>会社は事実上倒産</li>
</ul>
<h3>事例2:建設業の個人事業主(2022年)</h3>
<ul>
<li>売掛金200万円を、A社・B社に二重に譲渡</li>
<li>横領罪で略式起訴され、罰金80万円</li>
<li>取引先の信用を失い、廃業</li>
</ul>
<h3>事例3:ITスタートアップ経営者(2024年)</h3>
<ul>
<li>将来債権のファクタリングで、複数社に重複して譲渡</li>
<li>民事訴訟で2,000万円の損害賠償</li>
<li>経営者個人が破産</li>
</ul>
<hr>
<h2>違法業者から二重譲渡を勧められた場合の対応</h2>
<h3>❌ 行ってはならないこと</h3>
<ul>
<li>業者の言葉を信じて、他社にも申し込む</li>
<li>「知られない」と言われて契約する</li>
</ul>
<h3>✅ 行うべきこと</h3>
<ul>
<li>その場で契約を断る</li>
<li>業者名・連絡先を記録する</li>
<li><a href="/articles/article-factoring-kinyuuchou/">金融庁</a>・警察に通報する</li>
<li>弁護士に相談する</li>
</ul>
<p>「他社に知られない」と勧める業者は、違法業者であると考えられます。詳しくは<a href="/articles/article-factoring-ihou-gyousha/">違法業者の見分け方</a>をご覧ください。</p>
<hr>
<h2>ファクタリング会社から「登記なしの契約」を提案された場合</h2>
<p>債権譲渡登記なしの契約は、ファクタリング会社が二重譲渡のリスクを許容していることを示しています。</p>
<h3>メリット</h3>
<ul>
<li>登記費用（7,500円〜）が不要</li>
<li>売掛先に登記情報を知られない</li>
</ul>
<h3>デメリット</h3>
<ul>
<li>ファクタリング会社の自衛策が十分でない</li>
<li>結果として、手数料が高くなる（リスクの上乗せ）</li>
<li>利用者側にも、より高い誠実性が求められる</li>
</ul>
<p><a href="/articles/article-factoring-saiken-touki/">債権譲渡登記の詳細</a>を確認し、自社の状況に合わせて判断してください。</p>
<hr>
<h2>二重譲渡が発覚した場合の対処の流れ</h2>
<h3>段階1:発覚直後(24時間以内)</h3>
<ol>
<li>速やかに弁護士に連絡する</li>
<li>関連するすべての契約書・振込記録を保全する</li>
<li>二重譲渡の相手先に状況を説明する（意図しないミスの場合）</li>
</ol>
<h3>段階2:民事対応(1週間以内)</h3>
<ol>
<li>弁護士の同席のもとで各社と協議する</li>
<li>賠償・買戻しを交渉する</li>
<li>必要に応じて、和解金を準備する</li>
</ol>
<h3>段階3：刑事上のリスクへの対応</h3>
<ol>
<li>警察の聴取への対応</li>
<li>検察への意見書の提出</li>
<li>必要に応じて、自首も検討する（刑罰の軽減のため）</li>
</ol>
<h3>段階4：事業の継続の判断</h3>
<ol>
<li>取引先との関係の維持</li>
<li>銀行・金融機関への説明</li>
<li>廃業・事業再生の選択</li>
</ol>
<hr>
<h2>二重譲渡は禁止されています</h2>
<ul>
<li><strong>詐欺罪・横領罪・背任罪に問われるリスク</strong>がある</li>
<li>民事責任・刑事責任・信用の失墜という重大な影響がある</li>
<li>ファクタリング会社は、AI審査・登記の照会により、高い確率で発覚させる</li>
<li><a href="/articles/article-factoring-ihou-gyousha/">違法業者からの勧誘</a>には応じない</li>
<li>経済的に苦しい状況でも、決して行わない</li>
</ul>
<p>資金繰りに困った場合は、まず正規のファクタリング会社の<a href="/articles/article-factoring-osusume/">比較</a>や、<a href="/articles/article-factoring-vs-yuushi/">他の資金調達手段</a>をご検討ください。</p>
<hr>
<h2>よくある質問(FAQ)</h2>
<p><strong>Q: 意図せず二重譲渡してしまった場合は、どうなりますか？</strong>
A: 故意でなくても、民事責任は免れません。発覚後は速やかに弁護士・関係各社に事実を伝え、損害賠償の交渉を始めることが最善です。</p>
<p><strong>Q: 売掛先が承諾していれば、二重譲渡してもよいですか？</strong>
A: 売掛先の承諾があっても、ファクタリング会社をだましていれば詐欺罪にあたります。承諾の有無は関係ありません。</p>
<p><strong>Q: 一度譲渡した売掛金を買い戻し、別の会社に再譲渡することはできますか？</strong>
A: 買戻しの処理が完了していれば可能です。ただし、書面で「譲渡解除証明書」を必ず取得してください。</p>
<p><strong>Q: 過去に二重譲渡したことがあり、まだ発覚していません。どうすべきですか？</strong>
A: 早めに弁護士に相談してください。発覚後より、自主的に解決するほうが、刑事・民事のいずれにおいても有利に進められます。</p>
<p><strong>Q: 二重譲渡が発覚した会社のリスト等はありますか？</strong>
A: 公的なリストはありませんが、会社間の情報共有によりブラックリストに登録される可能性は高いといえます。以後、ファクタリングの利用が困難になるケースが多くあります。</p>
