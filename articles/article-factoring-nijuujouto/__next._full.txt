11:T29f8,<p>「同じ売掛金を2社に売ったらどうなる?」「資金に困っているからバレなければOK?」——その考え方は<strong>完全にアウト</strong>です。二重譲渡は民事だけでなく**刑事罰(詐欺罪・横領罪)**の対象になり、会社・個人事業ともに致命的なダメージを受けます。</p>
<p>この記事では、ファクタリングの二重譲渡が成立する仕組み、法的罪状、ファクタリング会社がどう検知するか、そして万が一発覚した場合の対処法まで解説します。</p>
<hr>
<h2>二重譲渡とは?定義と典型例</h2>
<p><strong>二重譲渡</strong>:同一の売掛債権を、異なる複数のファクタリング会社・債権者に重複して譲渡する行為。</p>
<h3>典型例</h3>
<ol>
<li>売掛金100万円をA社にファクタリング</li>
<li>その後、同じ売掛金をB社にもファクタリング</li>
<li>売掛先から100万円が入金されると、A社・B社両方が回収権を主張</li>
</ol>
<p>これは<strong>法的に成立しえない取引</strong>であり、明白な犯罪です。</p>
<hr>
<h2>二重譲渡の法的罪状</h2>
<h3>1. 詐欺罪(刑法246条)</h3>
<ul>
<li>法定刑:10年以下の懲役</li>
<li>既に他社に譲渡済みの債権を「未譲渡」と偽って契約 → 詐欺</li>
<li>ファクタリング会社が誤って買い取らされた → 損害が確定</li>
</ul>
<h3>2. 横領罪(刑法252条)</h3>
<ul>
<li>法定刑:5年以下の懲役</li>
<li>入金された100万円のうち、最初の譲渡先(A社)に渡すべき分を別の業者(B社)に渡す → 業務上横領</li>
</ul>
<h3>3. 背任罪(刑法247条)</h3>
<ul>
<li>法定刑:5年以下の懲役または50万円以下の罰金</li>
<li>経営者として会社の利益に反する取引 → 背任</li>
</ul>
<h3>4. 民事上の責任</h3>
<ul>
<li>損害賠償請求</li>
<li>利息損害金</li>
<li>弁護士費用負担</li>
<li>信用失墜による取引停止</li>
</ul>
<p>刑事+民事のダブルパンチを食らいます。</p>
<hr>
<h2>なぜ二重譲渡が起きてしまうのか?</h2>
<h3>パターン1:資金繰り悪化での誘惑</h3>
<p>急ぎの資金需要で「もう1社に売ってしまえばいい」と短絡的判断。</p>
<h3>パターン2:違法業者からの勧誘</h3>
<p><a href="/articles/article-factoring-ihou-gyousha/">違法業者</a>が「他社にもバレない」「審査が通る」と誘導。</p>
<h3>パターン3:管理ミス</h3>
<p>複数の売掛金を持つ企業が、どれを既に譲渡したか管理できていない。</p>
<h3>パターン4:意図的な詐欺行為</h3>
<p>最初から複数社に売る計画で書類を偽造する悪質ケース。</p>
<p>いずれのパターンでも、結果として刑事罰の対象になります。</p>
<hr>
<h2>ファクタリング会社はどう検知するか?</h2>
<h3>1. 債権譲渡登記の確認</h3>
<p>法人税滞納の影響で、ファクタリング会社の多くは<strong>債権譲渡登記ファイル</strong>を照会します。既に登記されていれば、即座に発覚。</p>
<h3>2. 売掛先への直接確認(3社間の場合)</h3>
<p>3社間ファクタリングでは売掛先に通知するため、既に他社が通知済みなら判明。</p>
<h3>3. 業者間情報共有</h3>
<p>業界団体加盟のファクタリング会社間で、ブラックリスト・利用履歴の情報交換が行われています。</p>
<h3>4. 入金履歴の照合</h3>
<p>売掛先から入金された場合、口座・金額・タイミングが既に他社に流れていないかを確認。</p>
<h3>5. AI審査による異常検知</h3>
<p>近年は<a href="/articles/article-factoring-ai-shinsa/">AI審査ファクタリング</a>が、過去の譲渡パターン・申込履歴を機械学習で異常検知します。</p>
<hr>
<h2>二重譲渡を防ぐための実務的対策</h2>
<h3>自分が利用者の場合</h3>
<h4>✅ 譲渡済み売掛金リストを管理</h4>
<p>スプレッドシートで「売掛先・金額・譲渡先・譲渡日」を必ず記録。</p>
<h4>✅ ファクタリング会社1社に絞る</h4>
<p>複数社利用は<a href="/articles/article-factoring-fukusu/">複数ファクタリングの併用</a>記事を参照のうえ、譲渡対象を明確に区分。</p>
<h4>✅ 契約時にチェックリスト確認</h4>
<p>申込時に「この売掛金は他社に譲渡していますか?」の質問に正直回答。</p>
<h4>✅ 顧問税理士・弁護士に相談</h4>
<p>複雑な売掛債権がある場合、専門家のレビューを通す。</p>
<hr>
<h2>二重譲渡における優先順位の法的ルール</h2>
<p>万一、二重譲渡が発生した場合、債権者間の優先順位はどう決まるか?</p>
<h3>民法467条:対抗要件</h3>
<ul>
<li><strong>第三者対抗要件</strong>:確定日付ある通知または承諾(売掛先への通知)</li>
<li><strong>債務者対抗要件</strong>:売掛先への通知</li>
</ul>
<h3>優先順位の決まり方</h3>
<ol>
<li><strong>登記の有無</strong>:<a href="/articles/article-factoring-saiken-touki/">債権譲渡登記</a>あり > なし</li>
<li><strong>登記がない場合</strong>:確定日付の早い者勝ち</li>
<li><strong>同じ日付</strong>:売掛先に先に到達した方が優先</li>
</ol>
<p>つまり、後から譲渡を受けたファクタリング会社が「登記または確定日付」を先に取れば、最初の譲渡先が負ける可能性すらあります。</p>
<p>→ ファクタリング会社が登記を急ぐのはこのため。</p>
<hr>
<h2>実際に起きた二重譲渡事件の事例</h2>
<h3>事例1:都内中小企業の経営者(2020年)</h3>
<ul>
<li>売掛金300万円を3社に重複譲渡</li>
<li>詐欺罪で起訴、懲役2年6ヶ月(執行猶予4年)</li>
<li>会社は事実上倒産</li>
</ul>
<h3>事例2:建設業の個人事業主(2022年)</h3>
<ul>
<li>売掛金200万円をA社・B社に二重譲渡</li>
<li>横領罪で略式起訴、罰金80万円</li>
<li>取引先の信用失墜で廃業</li>
</ul>
<h3>事例3:ITスタートアップ経営者(2024年)</h3>
<ul>
<li>将来債権ファクタリングで複数社に重複譲渡</li>
<li>民事訴訟で2,000万円の損害賠償</li>
<li>経営者個人破産</li>
</ul>
<hr>
<h2>違法業者が二重譲渡を勧めてきたらどうする?</h2>
<h3>❌ 絶対にやってはいけないこと</h3>
<ul>
<li>業者の言葉を信じて他社にも申込む</li>
<li>「バレない」と言われて契約</li>
</ul>
<h3>✅ すべきこと</h3>
<ul>
<li>その場で契約を断る</li>
<li>業者名・連絡先を記録</li>
<li><a href="/articles/article-factoring-kinyuuchou/">金融庁</a>・警察に通報</li>
<li>弁護士に相談</li>
</ul>
<p>「他社にバレない」と勧める業者は100%違法業者です。詳しくは<a href="/articles/article-factoring-ihou-gyousha/">違法業者の見分け方</a>を参照。</p>
<hr>
<h2>ファクタリング会社が「登記なし契約」を提案してきたら?</h2>
<p>債権譲渡登記なし契約は、二重譲渡リスクをファクタリング会社が許容している証拠でもあります。</p>
<h3>メリット</h3>
<ul>
<li>登記費用(7,500円〜)が不要</li>
<li>売掛先に登記情報が知られない</li>
</ul>
<h3>デメリット</h3>
<ul>
<li>ファクタリング会社の自衛策が薄い</li>
<li>結果的に手数料が高くなる(リスクプレミアム)</li>
<li>利用者側にも誠実性を強く求められる</li>
</ul>
<p><a href="/articles/article-factoring-saiken-touki/">債権譲渡登記の詳細</a>を確認し、自社の状況に合わせて判断してください。</p>
<hr>
<h2>二重譲渡が発覚した場合の対処フロー</h2>
<h3>段階1:発覚直後(24時間以内)</h3>
<ol>
<li>すぐに弁護士に連絡</li>
<li>関連する全契約書・振込記録を保全</li>
<li>二重譲渡先に状況説明(意図せぬミスの場合)</li>
</ol>
<h3>段階2:民事対応(1週間以内)</h3>
<ol>
<li>弁護士同席で各社と協議</li>
<li>賠償・買戻しの交渉</li>
<li>必要に応じて和解金準備</li>
</ol>
<h3>段階3:刑事リスク対応</h3>
<ol>
<li>警察聴取の対応</li>
<li>検察への意見書提出</li>
<li>必要なら自首も検討(刑罰軽減のため)</li>
</ol>
<h3>段階4:事業継続判断</h3>
<ol>
<li>取引先との関係維持</li>
<li>銀行・金融機関への説明</li>
<li>廃業/事業再生の選択</li>
</ol>

<li>民事責任+刑事責任+信用失墜のダメージ</li>
<li>ファクタリング会社はAI審査・登記照会で発覚率高い</li>

<h2>よくある質問(FAQ)</h2>
<p><strong>Q: 「うっかり」二重譲渡してしまったらどうなる?</strong>
A: 故意でなくても民事責任は免れません。発覚後すぐに弁護士・関係各社に正直に伝え、損害賠償の交渉を始めるのが最善です。</p>
<p><strong>Q: 売掛先が承諾していれば二重譲渡してもいい?</strong>
A: 売掛先の承諾があっても、ファクタリング会社をだましていれば詐欺罪です。承諾の有無は関係ありません。</p>
<p><strong>Q: 一度譲渡した売掛金を買い戻して、別の会社に再譲渡するのはOK?</strong>
A: 完全に買戻し処理が完了していればOK。ただし書面で「譲渡解除証明書」を必ず取得してください。</p>
<p><strong>Q: 過去に二重譲渡したことがあるが、まだ発覚していない。どうすべき?</strong>
A: 早めに弁護士に相談を。発覚後より、自主的解決の方が刑事・民事ともに有利に進められます。</p>
<p><strong>Q: 二重譲渡が発覚した会社のリスト等はある?</strong>
A: 公的なリストはありませんが、業者間情報共有でブラックリスト化される可能性は高いです。今後一切のファクタリング利用が困難になるケースが多いです。</p>
