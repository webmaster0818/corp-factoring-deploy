<h2>給与の支払いについて法律で決まっていること</h2>
<h3>労働基準法24条の「全額」「毎月1回以上」「一定の期日」</h3>
<p>労働基準法24条1項は「賃金は、通貨で、直接労働者に、その全額を支払わなければならない」と定め、同条2項は「賃金は、毎月一回以上、一定の期日を定めて支払わなければならない」と定めています（出典：e-Gov法令検索 労働基準法、2026年10月31日確認）。</p>
<p>この条文から、資金が足りないときの判断について、次の点が言えます。</p>
<ul>
<li>給与の一部だけを先に払い、残りを翌月に回すことは、「全額」払いの定めに沿いません</li>
<li>就業規則などで定めた支払日（一定の期日）を過ぎることは、2項の定めに沿いません</li>
<li>24条には、従業員の同意があれば支払期日を後ろにずらせる、という定めはありません</li>
</ul>
<h3>違反した場合の罰則と、支払いが遅れた賃金の扱い</h3>
<p>労働基準法120条1号は、24条を含む条文に違反した者を「三十万円以下の罰金に処する」と定めています（出典：e-Gov法令検索 労働基準法120条、2026年10月31日確認）。</p>
<p>また、退職した従業員の賃金（退職手当を除く）を退職日（退職日より後に支払期日が来る賃金はその支払期日）までに支払わなかった場合、事業主はその翌日から支払日までの遅延利息を支払う義務を負います（賃金の支払の確保等に関する法律6条1項）。その率は、同法施行令1条で「年十四・六パーセント」と定められています（出典：e-Gov法令検索、2026年10月31日確認）。</p>
<p>賃金の請求権の時効は、労働基準法115条で5年と定められていますが、同法附則143条3項により、当分の間、退職手当を除く賃金は3年とされています（出典：e-Gov法令検索 労働基準法、2026年10月31日確認）。</p>

<h2>今日やること：不足額を確定し、給与以外の支払いを動かす</h2>
<h3>給与日までの入出金を1枚に書き出す</h3>
<p>最初に、給与日までに確実に入る入金と、出ていく支払いを日付順に書き出します。給与については、支給総額ではなく、口座から実際に出ていく金額（差引支給額の合計と、振込手数料）で見積もります。源泉所得税や住民税、社会保険料の預り分は、給与日には出ていかず、それぞれの納付期限に出ていくためです。</p>

<h3>支払先に支払日の変更を相談する</h3>
<p>外注費・仕入れ代・家賃・リース料などは、相手との合意で支払日を変えられる場合があります。相談する際は、次の3点を具体的に伝えると、相手も判断しやすくなります。</p>
<ul>
<li>いつ、いくらなら支払えるか（日付と金額を明示する）</li>
<li>その日付に支払える根拠（売掛金の入金予定日など）</li>
<li>今後の取引への影響を避けたいという意思</li>
</ul>
<p>相手の資金繰りにも影響するため、合意が得られるとは限りません。</p>
<h3>売掛金があれば、見積もりの依頼を当日中に出す</h3>
<p>まだ入金されていない売掛金（請求済みの請求書）がある場合は、ファクタリングで給与日より前に現金化できる可能性があります。審査と契約に時間がかかるため、見積もりの依頼は、他の手段と並行して今日のうちに出しておくと選択肢が残ります。詳しくは後半の「売掛金がある場合のファクタリングの位置づけ」でご説明します。</p>

<h2>今週やること：税金・社会保険料の猶予と公的融資</h2>
<h3>国税の猶予制度（国税庁）</h3>
<p>国税庁は、国税を一時に納付することで事業の継続などが困難になる場合について、「税務署に申請することで、原則として１年以内の期間に限り、納税が猶予される制度」があると案内しています。猶予制度には、換価の猶予（国税徴収法151条・151条の2）と納税の猶予（国税通則法46条）があります（出典：国税庁「納税に関する総合案内」、2026年10月31日確認）。</p>
<p>資金繰りの悪化が理由の場合に関係が深いのは、申請による換価の猶予です。国税庁の案内では、次の要件にあてはまる場合に「納付すべき国税の納期限から６か月以内に申請することにより、換価の猶予を受けることができます」とされています。</p>
<ul>
<li>国税を一時に納付することで、事業の継続または生活の維持を困難にするおそれがある</li>
<li>納税について誠実な意思を有すると認められる</li>
<li>猶予を受けようとする国税以外の国税の滞納がない</li>
<li>原則として、担保の提供がある（猶予を受ける金額が100万円以下、猶予期間が3か月以内、提供できる担保がない場合は不要）</li>
</ul>
<p>認められると、猶予期間中の延滞税が軽減され、財産の差押えや換価（売却）が猶予されます。猶予期間中は分割で納付する場合があり、分割額は納税者の資力に応じて決まります。</p>
<p>給与日の前後に源泉所得税や消費税などの納付が重なる場合、その納付を分割にできれば、給与に回せる資金が残ります。税金を滞納している状態でのファクタリングの扱いは<a href="/articles/article-factoring-zeikin/">税金滞納でもファクタリングは利用できるか</a>で扱っています。</p>
<h3>厚生年金保険料等の猶予制度（日本年金機構）</h3>
<p>社会保険料にも同じような制度があります。日本年金機構は、厚生年金保険料等の納付が困難なときは、事業主が申請し一定の要件を満たせば「換価の猶予」や「納付の猶予」を受けられると案内しています（出典：日本年金機構「厚生年金保険料等の猶予（換価の猶予・納付の猶予）」、2026年10月31日確認）。</p>
<ul>
<li><strong>換価の猶予：</strong> 一時に納付すると事業の継続などを困難にするおそれがあり、納付に誠実な意思がある場合に、猶予を受けようとする保険料等の納期限から6カ月以内に年金事務所へ申請します。認められると保険料等を分割して納付でき、同機構の案内では「猶予期間における延滞金の一部が免除」されます</li>
<li><strong>納付の猶予：</strong> 災害による財産の損失、事業の休廃業、事業についての著しい損失などで一時に納付できない場合が対象です。日本年金機構の概要資料では、「著しい損失」を「申請前の１年間において、その前年の利益の額の２分の１を超える損失（赤字）を生じた場合」と説明しています</li>
</ul>
<p>同機構の概要資料によると、猶予期間は1年の範囲内で、やむを得ない理由がある場合は当初の期間とあわせて最長2年まで延長を申請できます。猶予を受けずに納付期限を過ぎると督促状が届き、指定期限を過ぎると延滞金が発生することがあるため、同機構は早めに管轄の年金事務所へ相談するよう求めています。</p>

<h2>売掛金がある場合のファクタリングの位置づけ</h2>
<h3>借入ではなく、売掛金の売却</h3>
<p>ファクタリングは、金融庁の説明では「事業者が保有している売掛債権等を期日前に一定の手数料を徴収して買い取るサービス」であり、「法的には債権の売買（債権譲渡）契約」です（出典：金融庁「ファクタリングの利用に関する注意喚起」、2026年10月31日確認）。</p>
<p>借入ではないため、融資のような返済計画の審査とは手続きが異なり、次の項でご説明するとおり、多くの会社が「最短即日」などの短い入金時間を公式に表示しています。給与日までの日数が少ない場面で選択肢になるのはこのためです。一方で、売掛金の額面から手数料が差し引かれるため、受け取る金額は額面より少なくなります。</p>
<p>例：前の表の会社が、額面150万円の売掛金を売却する場合（仮定）</p>
<ul>
<li>手数料率を10%と仮定すると、手数料は15万円、入金額は135万円です</li>
<li>不足額120万円を埋めたうえで、15万円が手元に残る計算です</li>
<li>実際の手数料率は、売掛先の信用力や契約形態（2社間・3社間）により見積もりで決まります。ここでの10%は計算のための仮定で、相場を示すものではありません</li>
</ul>
<h3>当サイトの調査：「最短即日」の表示と、同じ公式サイト内の別の目安</h3>
<p>当サイトが各社の公式サイトで確認した36社（2026年7月21日〜10月31日確認）のうち、最短入金を「最短即日」「最短○時間」「最短○分」と表示している会社は32社でした。「最短6時間」のような表示も含むため、申込時刻によっては当日中に入らない場合があります。ほかの4社は、「通常即日から数日程度」（最短の表示なし）、「最短1日」、「最短2営業日」、「最短5営業日」の表示です。このうち「最短1日」の会社は、公式サイトによって「最短即日」の表記もあります。</p>
<p>最短の表示は条件がそろった場合の値です。32社のうち13社は、同じ公式サイト内に、時間帯・契約形態などによって当日中に入金されない場合があることを示す記載もありました（当サイトの確認データにある記載で数えています）。</p>

<h3>即日入金に向けて手元に用意するもの</h3>
<p>必要書類は会社によって異なるため、申し込む会社の公式サイトで確認が必要です。給与日が迫っている場合に、事前にそろえておくと手続きを進めやすい書類の例は次のとおりです。</p>
<ul>
<li>売却する売掛金の請求書（売掛先・金額・支払期日が分かるもの）</li>
<li>売掛先との取引が分かる資料（契約書・発注書・過去の入金履歴など）</li>
<li>事業用口座の入出金明細（期間は各社の指定による）</li>
<li>本人確認書類、法人の場合は登記事項証明書など</li>
</ul>
<h3>ファクタリングを使う前に確かめること</h3>
<ul>
<li><strong>売掛金の譲渡を禁止する特約の有無：</strong> 売掛先との契約書に譲渡制限の条項があるかを確認します</li>
<li><strong>同じ売掛金を複数の会社に売らないこと：</strong> 二重譲渡の問題点は<a href="/articles/article-factoring-nijuujouto/">ファクタリングの二重譲渡</a>で扱っています</li>
<li><strong>偽装ファクタリングではないか：</strong> 金融庁は、売主が債権を買い戻すこととされている契約などは「貸金業に該当するおそれがあります」と注意を促しています。業者の見分け方は<a href="/articles/article-factoring-ihou-gyousha/">違法業者の見分け方</a>をご覧ください</li>
<li><strong>翌月の資金繰り：</strong> 売掛金を前倒しで受け取ると、本来その売掛金が入るはずだった月の入金がなくなります。翌月も同じ不足が生じないか、資金繰り表で確かめてから利用してください</li>
</ul>
<h3>「給料ファクタリング」とは別のもの</h3>
<p>検索結果には「給料ファクタリング」という言葉が並ぶことがありますが、これは会社員が自分の給与を業者に売る形をとった個人向けの取引で、会社の資金繰りに使う事業者向けファクタリングとは別のものです。金融庁は、この手法は貸金業に該当するとし、年率換算で数百〜千数百％になる手数料や悪質な取立ての被害を受ける危険性があるとして、利用しないよう呼びかけています。違いと最高裁の判断は<a href="/articles/article-factoring-kyuuryo-gisou/">偽装給与ファクタリングの実態と見抜き方</a>で詳しくご説明しています。</p>

<p>給与を口座振込で支払っている場合、振込データには金融機関ごとに締切があり、給与日の当日に入金を受けても間に合わないことがあります。締切の時刻は取引銀行で確認してください。</p>
<hr>
<h2>給与日に間に合わない場合の対応</h2>
<p>それでも間に合わない場合は、支払えない金額と支払える見込みの日付を、給与日より前に従業員へ伝えます。支払義務はなくなりませんが、従業員が自身の支払いの手当てをする時間を確保できます。顧問の社会保険労務士や弁護士がいる場合は、事前に相談してください。</p>
<h3>従業員の方へ：会社が倒産した場合の未払賃金立替払制度</h3>
<p>会社が倒産したために賃金が支払われないまま退職した場合は、国（労働者健康安全機構）が未払賃金の一部を事業主に代わって支払う「未払賃金立替払制度」があります（賃金の支払の確保等に関する法律7条）。</p>
<p>厚生労働省のQ&#x26;Aによると、主な内容は次のとおりです（出典：厚生労働省「未払賃金の立替払制度に関するQ&#x26;A」、2026年10月31日確認）。</p>
<ul>
<li>対象は、法律上の倒産（破産手続開始決定など）または労働基準監督署長が認定した事実上の倒産（中小企業に限る）</li>
<li>対象となる賃金は、退職日の6か月前から立替払請求日の前日までに支払期日が到来している定期給与と退職金（ボーナスは対象外。総額2万円未満は対象外）</li>
<li>立替払の額は未払賃金総額の8割で、退職日の年齢に応じた上限額がある</li>
</ul>
<p>この制度は会社の倒産が前提であり、給与が遅れている会社で働き続けている段階では使えません。詳しい要件は、厚生労働省のQ&#x26;Aまたは最寄りの労働基準監督署でご確認ください。</p>

<h2>よくある質問</h2>
<p><strong>Q: 給与を一部だけ先に払い、残りを翌週に払うことはできますか？</strong>
A: 労働基準法24条は、賃金を毎月1回以上、一定の期日に「その全額」を支払うよう定めています。一部だけの支払いは、この定めに沿いません。条文には従業員の同意で期日をずらせるという定めもないため、不足分を埋める手段を給与日前に講じることが基本です。</p>
<p><strong>Q: 税金や社会保険料を後回しにして、給与に回してもよいですか？</strong>
A: 国税は納期限の翌日から延滞税がかかり、社会保険料は督促状の指定期限を過ぎると延滞金が発生することがあります。国税庁と日本年金機構には、要件を満たせば分割納付ができる「換価の猶予」があり、いずれも納期限から6か月以内に申請します。黙って支払いを止めるのではなく、税務署・年金事務所に申請・相談することで、延滞税・延滞金の軽減や差押えの猶予を受けられる場合があります。</p>
<p><strong>Q: 給与日の前日にファクタリングを申し込んでも間に合いますか？</strong>
A: 当サイトが確認した36社のうち32社は「最短即日」または「最短○時間・○分」と公式に表示していますが、これは条件がそろった場合の最短の値です。そのうち13社は、同じ公式サイト内に「平均2.3日」「申込の時間帯により翌営業日」といった別の目安も記載しています。前日の申込みでは間に合わない可能性があるため、見積もりの段階で入金の日時を具体的に確認し、支払先への支払日の相談も並行して進めてください。</p>
<p><strong>Q: 日本政策金融公庫の融資で、今月の給与に間に合いますか？</strong>
A: 公庫のセーフティネット貸付には審査があるため、数日後の給与日の資金として計画するのは難しいと考えられます。今月分は支払日の調整や売掛金の資金化で対応し、公庫には来月以降の資金繰りの立て直しとして相談するのが現実的です。</p>
<hr>
<h2>まとめ</h2>
<ul>
<li>給与は労働基準法24条により、毎月1回以上、一定の期日に全額を支払う必要があります。違反には同法120条で30万円以下の罰金が定められています</li>
<li>給料が払えない見込みになったら、今日中に不足額を確定し、給与以外の支払いの調整と売掛金の資金化を同時に進めます</li>
<li>税金・社会保険料は、国税庁・日本年金機構の「換価の猶予」で分割納付を申請できる場合があります。いずれも納期限から6か月以内の申請です</li>
<li>日本政策金融公庫のセーフティネット貸付は、審査があるため、来月以降の立て直しの手段として今週から相談します</li>
<li>売掛金があればファクタリングは選択肢の一つです。当サイトの調査では36社中32社が「最短即日」または「最短○時間・○分」と公式に表示していますが、そのうち13社は当日中に入金されない場合を示す記載も併せて載せているため、入金日時は見積もりで具体的に確認してください</li>
</ul>
<p>各制度の要件や金額は改正される場合があります。ご利用前に、国税庁・日本年金機構・日本政策金融公庫・各ファクタリング会社の公式サイトにて最新情報をご確認ください。</p>
