4:T32a7,<p>ファクタリングをめぐって裁判で争われた例や、過去の判例で違法とされたケースについて解説します。ファクタリングの法的な位置付けは、過去20年で大きく変わってきました。複数の最高裁判例・地裁判決が、業界の慣行を形作っています。</p>
<p>この記事では、ファクタリングを利用する経営者・個人事業主が把握しておくべき重要判例8選を解説します。</p>
<hr>
<h2>判例を把握しておくべき理由</h2>
<p>ファクタリングには、明確な業法（銀行法・貸金業法のような専門の法律）がありません。そのため、適法・違法の境界は、<strong>判例によって形成</strong>されています。</p>
<p>判例を把握することには、以下の意義があります。</p>
<ul>
<li>違法業者を見分けやすくなる</li>
<li>自社の契約にリスクのある内容が含まれているかがわかる</li>
<li>トラブルの発生時に、交渉の根拠となる</li>
</ul>
<p><a href="/articles/article-factoring-osusume/">ファクタリング会社を選ぶ際</a>に、契約形態が判例上問題ないかを確認できます。</p>
<hr>
<h2>重要判例1：最高裁 平成29年12月19日（ファクタリング適法判決）</h2>
<h3>事案</h3>
<p>ファクタリング会社A社と中小企業Bが、2社間ファクタリング契約を締結しました。後にBが、契約は実質的な貸付であり利息制限法に違反すると主張しました。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>債権譲渡契約による真正売買である限り、貸金業法・利息制限法の適用外</strong>」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>2社間ファクタリングが、正式に合法と認められた</li>
<li>業界の急成長（2020年以降で3倍）</li>
<li>ノンリコース契約の確立</li>
</ul>
<p><a href="/articles/article-factoring-non-recourse/">ノンリコースの解説</a>もご覧ください。</p>
<hr>
<h2>重要判例2：最高裁 令和2年3月5日（給与ファクタリング違法判決）</h2>
<h3>事案</h3>
<p>給与ファクタリング会社X社が、会社員Yの給与30万円を25万円で買い取りました。Yが返済できなくなり、訴訟となりました。</p>
<h3>判断</h3>
<blockquote>
<p>「給与は労基法24条により本人にのみ支払われる。<strong>給与債権譲渡は実質貸付であり、貸金業登録なしの業者の取扱は違法</strong>」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>給与ファクタリング業界が、事実上消滅</li>
<li>偽装した仕組みの出現（<a href="/articles/article-factoring-kyuuryo-gisou/">偽装給与ファクタリング</a>へ）</li>
<li>既払い金の返還請求が可能に</li>
</ul>
<hr>
<h2>重要判例3：東京地裁 平成26年1月17日（リコース型契約の無効）</h2>
<h3>事案</h3>
<p>ファクタリング会社Cが、利用者Dとの契約に「売掛先が支払いを拒否した場合は買い戻す」というリコース条項を入れました。後に売掛先が倒産し、Cが買戻しを請求しました。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>リコース型契約は実質的貸付であり、貸金業登録のないCの行為は違法</strong>」「契約自体が公序良俗違反で無効」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>リコース契約が事実上禁止された</li>
<li>「買戻し義務」の条項がある業者は、違法業者として扱われるようになった</li>
</ul>
<hr>
<h2>重要判例4：東京地裁 令和3年2月10日（高利のファクタリングの無効）</h2>
<h3>事案</h3>
<p>ファクタリング会社Eが、手数料35%（年率140%超）で契約しました。利用者Fが、利息制限法違反であると主張しました。</p>
<h3>判断</h3>
<blockquote>
<p>「形式的にはファクタリングだが、<strong>実質的に利息制限法を潜脱した違法貸付</strong>」「契約無効、既払い金返還義務あり」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>手数料20%以上のケースで、違法と判断される根拠となった</li>
<li>利息制限法による上限規制が、事実上適用されるようになった</li>
<li><a href="/articles/article-factoring-tesuryo/">手数料相場</a>に関する業界の自主基準が確立された</li>
</ul>
<hr>
<h2>重要判例5：大阪地裁 令和元年5月23日（架空債権を用いた詐欺の有罪判決）</h2>
<h3>事案</h3>
<p>ファクタリング会社G社の代表者と利用者Hが共謀し、架空の請求書で売掛金を装い、複数の会社から資金を調達しました。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>詐欺罪が成立</strong>。G代表は懲役4年、Hは懲役2年6ヶ月(執行猶予)」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>架空債権は、明確な詐欺罪にあたる</li>
<li>ファクタリング会社による本人確認・実在性の確認が強化された</li>
<li>利用者側も共犯となり得ることが示された</li>
</ul>
<p><a href="/articles/article-factoring-sagi/">ファクタリング詐欺の事例</a>もご覧ください。</p>
<hr>
<h2>重要判例6：東京地裁 令和4年7月15日（二重譲渡の有罪判決）</h2>
<h3>事案</h3>
<p>建設業の経営者Iが、同じ売掛金500万円を、3社のファクタリング会社に重複して譲渡しました。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>詐欺罪・横領罪が成立</strong>。懲役2年8ヶ月(実刑)」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li><a href="/articles/article-factoring-nijuujouto/">二重譲渡</a>は、明確な刑事犯罪である</li>
<li>ファクタリング会社による債権譲渡登記の照会が標準化された</li>
<li>利用者に対する厳しい判断が示された</li>
</ul>
<hr>
<h2>重要判例7：東京地裁 令和3年11月8日（取り立て・脅迫の違法性）</h2>
<h3>事案</h3>
<p>ファクタリング会社Jが取り立てのために自宅・職場・取引先に連絡し、利用者Kが精神的苦痛を理由に訴訟を提起しました。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>業者の取り立て行為は違法</strong>。慰謝料50万円、行為差止」</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>ファクタリング業界での取り立てのルールの整備</li>
<li>違法業者を排除する根拠</li>
<li>利用者の人格権の保護</li>
</ul>
<hr>
<h2>重要判例8：東京地裁 令和5年9月12日（債権譲渡登記の対抗要件）</h2>
<h3>事案</h3>
<p>売掛金1000万円が、A社→B社の順で二重に譲渡されました。B社が先に債権譲渡登記を行い、A社は回収できませんでした。</p>
<h3>判断</h3>
<blockquote>
<p>「<strong>登記が先のB社が優先</strong>、A社は売掛金の回収不可」(民法467条)</p>
</blockquote>
<h3>影響</h3>
<ul>
<li>債権譲渡登記の重要性が、法的に確立された</li>
<li>ファクタリング会社が登記を急ぐ理由となっている</li>
<li><a href="/articles/article-factoring-saiken-touki/">債権譲渡登記</a>に関する実務の指針となっている</li>
</ul>
<hr>
<h2>判例から導かれる「適法なファクタリング」の条件</h2>
<p>判例を総合すると、適法と認められるファクタリングは、以下の条件を満たす必要があります。</p>
<h3>✅ 条件1：真正な売買</h3>
<ul>
<li>売掛債権を譲渡する契約であること</li>
<li>名目だけでなく、実態として売買であること</li>
</ul>
<h3>✅ 条件2：ノンリコース（償還請求権なし）</h3>
<ul>
<li>売掛先の倒産時に、利用者の責任がないこと</li>
<li>買戻し義務・保証義務がないこと</li>
</ul>
<h3>✅ 条件3：適正な手数料</h3>
<ul>
<li>手数料は20%程度を上限の目安とする（利息制限法に準拠）</li>
<li>30%以上は、違法と判断されるリスクがある</li>
</ul>
<h3>✅ 条件4：給与・年金・補助金等は対象外</h3>
<ul>
<li>これらは、法律上譲渡が禁止されている</li>
<li>法人・個人事業主の事業上の売掛金のみが対象</li>
</ul>
<h3>✅ 条件5：適切な書面と説明</h3>
<ul>
<li>契約書の作成と控えの交付</li>
<li>重要事項の説明</li>
</ul>
<hr>
<h2>利用者側の訴訟のリスク</h2>
<p>ファクタリングの利用者が訴訟に巻き込まれる主なケースは、以下のとおりです。</p>
<h3>1. 二重譲渡 → 詐欺罪・横領罪</h3>
<p><a href="/articles/article-factoring-nijuujouto/">詳細</a></p>
<h3>2. 架空債権の作成 → 詐欺罪</h3>
<p><a href="/articles/article-factoring-sagi/">詳細</a></p>
<h3>3. 違法業者との共謀 → 共犯</h3>
<p><a href="/articles/article-factoring-ihou-gyousha/">違法業者への対策</a></p>
<h3>4. 売掛先への虚偽の説明 → 民事責任</h3>
<p>売掛先に対し、3社間であると偽って契約を締結するケースです。</p>
<h3>5. 税務調査での否認 → 追徴課税</h3>
<p><a href="/articles/article-factoring-kanjokamoku/">勘定科目・仕訳</a>を誤ると、否認されるリスクがあります。</p>
<hr>
<h2>ファクタリング会社選びで判例上のリスクを下げる方法</h2>
<h3>確認すべき項目</h3>
<ol>
<li><strong>過去の判例の検索</strong>：社名で訴訟の事例がないかを確認する</li>
<li><strong>業界団体への加盟</strong>：日本ファクタリング業協会等</li>
<li><strong>顧問弁護士の有無</strong>：公式サイトでの明記</li>
<li><strong>警告の対象でないこと</strong>：消費者庁・金融庁の警告の履歴を確認する</li>
</ol>
<p><a href="/articles/article-factoring-hikaku/">ファクタリング会社の比較</a>を参考に、訴訟歴のない優良なファクタリング会社を選んでください。</p>
<hr>
<h2>訴訟になった場合の対応の流れ</h2>
<h3>万一トラブルが発生した場合</h3>
<ol>
<li><strong>証拠の保全</strong>：契約書・通帳・メール・LINEをすべて保存する</li>
<li><strong>弁護士への相談</strong>：ファクタリング・金融トラブルを専門とする弁護士に相談する</li>
<li><strong>業者との直接の交渉は、弁護士を通じて行う</strong></li>
<li><strong>訴訟への移行</strong>：民事・刑事の両面で検討する</li>
<li><strong>損害賠償・返還請求</strong>：過払い分を取り戻す</li>
</ol>
<h3>相談先</h3>
<ul>
<li>法テラス（日本司法支援センター）</li>
<li>各地弁護士会の専門相談窓口</li>
<li>全国消費生活センター(188)</li>
</ul>
<hr>
<h2>まとめ</h2>
<ul>
<li>ファクタリングは、判例で適法性が確立している（H29.12.19 最高裁）</li>
<li>給与ファクタリングは違法（R2.3.5 最高裁）</li>
<li>リコース型・高い手数料の契約は、違法と判断されるリスクがある</li>
<li><a href="/articles/article-factoring-non-recourse/">ノンリコース</a>・<a href="/articles/article-factoring-tesuryo/">適正な手数料</a>の契約が安全</li>
<li>ファクタリング会社選びには、判例の情報も活用する</li>
</ul>
<p>判例の知識は、自社を守るために重要です。</p>
<hr>
<h2>よくある質問(FAQ)</h2>
<p><strong>Q: 過去の判例は、どこで確認できますか？</strong>
A: 裁判所の公式サイト（courts.go.jp）で、判決の全文を閲覧できます。商用の判例データベース（LEX/DBなど）も利用できます。</p>
<p><strong>Q: 業者が判例と異なる主張をしています。どうすべきですか？</strong>
A: 判例が法的根拠として強い場合が多くあります。弁護士に契約書を確認してもらい、判断してください。</p>
<p><strong>Q: 自社が裁判の当事者になりました。費用はどのくらいかかりますか？</strong>
A: 訴額・事件の複雑さによって異なります。一般的には、着手金20〜50万円、成功報酬15〜20%程度です。法テラスの支援制度も活用できます。</p>
<p><strong>Q: ファクタリング会社の経営者として、訴訟のリスクを下げるには、どうすればよいですか？</strong>
A: 弁護士が監修した契約書、明確なノンリコース条項、適正な手数料、丁寧な説明の履行が基本です。</p>
<p><strong>Q: 個人事業主でも訴訟を提起できますか？</strong>
A: 提起できます。被害が10万円以上であれば、民事訴訟を提起する経済的な合理性があります。少額訴訟（60万円以下）の制度も活用できます。</p>
