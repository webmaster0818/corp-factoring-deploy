4:T2d9a,<p>ファクタリングが金融庁の管轄か、監督を受けていない業者を利用して問題ないかといった疑問をお持ちの方に向けて解説します。ファクタリングには銀行や貸金業者のような業法や登録制度がないため、金融庁の関与は限定的です。ただし、過去数年にわたり、<strong>金融庁の警告・指導が業界に大きな影響を与えてきました</strong>。</p>
<p>この記事では、金融庁とファクタリングの関係、規制の動向、利用者が把握しておくべき情報を解説します。</p>
<hr>
<h2>ファクタリングは金融庁の直接監督対象ではない</h2>
<h3>登録制度はない</h3>
<ul>
<li>銀行業：銀行法にもとづき、金融庁の登録が必須</li>
<li>貸金業：貸金業法にもとづき、登録が必須</li>
<li><strong>ファクタリング:登録制度なし</strong></li>
</ul>
<h3>理由</h3>
<p>ファクタリングは「債権の売買」であり、貸付・融資ではないため、金融商品取引法等の規制の対象外です。</p>
<p><a href="/articles/article-factoring-kashikingyou/">ファクタリングが貸金業法に該当しない理由</a>もあわせてご覧ください。</p>
<hr>
<h2>金融庁がファクタリングに関わる主な場面</h2>
<h3>1. 違法業者（偽装給与ファクタリング等）の取締り</h3>
<p>金融庁は、違法なファクタリング会社を無登録の貸金業者として取り締まる権限を持っています。</p>
<h3>2. 注意喚起・警告の発出</h3>
<p>利用者向けに、悪質業者への注意喚起を継続的に発出しています。</p>

<h2>金融庁の主な公式見解・注意喚起（時系列）</h2>
<p>当サイトでは、金融庁の公式サイトで日付を確認できたものを掲載しています（2026年10月17日確認）。</p>
<h3>2020年3月5日：給与ファクタリングは貸金業に該当するとの解釈</h3>
<ul>
<li>「一般的な法令解釈に係る書面照会手続」への回答で、個人（労働者）の賃金債権を買い取って金銭を交付し、当該個人を通じて資金を回収するスキームを業として行う者は「貸金業」に該当するとの解釈を示しました</li>
<li>出典：<a href="https://www.fsa.go.jp/common/noact/kaitou_2/kashikin/index.html">金融庁 照会に対する回答（貸金業法）</a></li>
</ul>
<h3>2020年4月28日：高額な手数料のファクタリングに関する注意喚起リーフレット</h3>
<ul>
<li>高額な手数料を支払う契約を締結した場合、かえって資金繰りが悪化し、多重債務に陥る危険性があるとして注意を呼びかけました</li>
<li>出典：<a href="https://www.fsa.go.jp/user/factaringkigyouomote.pdf">金融庁 リーフレット（PDF）</a></li>
</ul>
<h3>2023年2月20日：給与ファクタリングに関する最高裁判所の決定</h3>
<ul>
<li>最高裁判所が、給与ファクタリングによる金銭の交付は貸金業法・出資法にいう「貸付け」にあたると判断しました。金融庁は、この決定の抜粋を注意喚起ページに掲載しています</li>
<li>出典：<a href="https://www.courts.go.jp/hanrei/91800/detail2/index.html">裁判所 裁判例検索</a></li>
</ul>
<h3>現在：「ファクタリングの利用に関する注意喚起」ページ</h3>
<ul>
<li>ファクタリングを装ったヤミ金融業者への注意喚起、貸金業に該当するおそれがある取引の例、関連する裁判例を掲載しています</li>
<li>出典：<a href="https://www.fsa.go.jp/user/factoring.html">金融庁「ファクタリングの利用に関する注意喚起」</a></li>
</ul>

<h2>金融庁が示す「貸金業に該当するおそれがある取引」</h2>
<p>金融庁の「ファクタリングの利用に関する注意喚起」の内容を、当サイトで整理すると以下のとおりです。</p>
<h3>✅ 金融庁の基本的な説明</h3>
<ol>
<li>ファクタリングは、事業者が保有している売掛債権等を期日前に一定の手数料を徴収して買い取るサービスであり、<strong>法的には債権の売買（債権譲渡）契約</strong>です</li>
<li>貸金業に該当するかどうかは、契約書に<strong>ノンリコースの規定があるかなどの形式的な要素だけでなく</strong>、経済的側面や実態に照らして判断されます</li>
<li>個人が使用者に対して有する賃金債権を買い取る<strong>給与ファクタリング</strong>は、貸金業に該当します</li>
</ol>
<h3>❌ 注意が必要な取引</h3>
<ol>
<li>回収を委託された売主が集金できなかった場合に、<strong>売主が債権を買い戻す</strong>こととされている取引</li>
<li>同じく、<strong>売主自身の資金</strong>により業者に支払をしなければならないこととされている取引</li>
<li>買取代金が債権額に比べて<strong>著しく低額</strong>である取引（偽装ファクタリングの疑い）</li>
<li>業務の平穏を害するような<strong>悪質な取立て</strong></li>
</ol>

<h2>金融庁が推奨する利用者のチェック項目</h2>
<p>金融庁の公式サイトの注意喚起ページから、利用者が確認すべき項目を要約しました。</p>
<h3>Q1：契約相手は誰か</h3>
<ul>
<li>法人格があり、登記情報を確認できるか</li>
<li>業界団体に加盟しているか</li>
</ul>
<h3>Q2：契約内容は適法か</h3>
<ul>
<li>償還請求権なし（ノンリコース）か</li>
<li>手数料は合理的か</li>
</ul>
<h3>Q3：取引の対象は適切か</h3>
<ul>
<li>事業者の売掛金か</li>
<li>個人の給与（賃金債権）や公的年金の受給権など、ファクタリングの対象とならないものではないか</li>
</ul>
<h3>Q4：契約書は適切か</h3>
<ul>
<li>書面で交付されているか</li>
<li>控えが手元にあるか</li>
</ul>
<h3>Q5：取り立ての方法は適法か</h3>
<ul>
<li>脅迫的・暴力的な取り立てではないか</li>
</ul>
<p>詳しくは<a href="/articles/article-factoring-ihou-gyousha/">違法業者の見分け方</a>をご覧ください。</p>

<h2>よくある質問(FAQ)</h2>
<p><strong>Q: ファクタリング会社は金融庁の登録制ですか？</strong>
A: 2026年現在、登録制ではありません。</p>
<p><strong>Q: 業者の悪質な行為を金融庁に通報したい場合、どこに連絡すればよいですか？</strong>
A: 金融サービス利用者相談室（0570-016811）または地方財務局にご連絡ください。詐欺被害の場合は、警察にも届け出てください。</p>
<p><strong>Q: 金融庁が公認している業者のリストはありますか？</strong>
A: ありません。業界団体の加盟業者リストや、金融機関の系列会社が、公認に近い位置付けといえます。</p>
<p><strong>Q: 利用前に金融庁に問い合わせて確認できますか？</strong>
A: 業者の登録状況（貸金業登録のあるファクタリング会社の場合）は確認できます。それ以外の業者は登録の対象外のため、確認できません。</p>
<p><strong>Q: 金融庁が定める手数料の上限はありますか？</strong>
A: 明示的な上限はありません。利息制限法を類推して、年率20%が一つの目安とされています。詳しくは<a href="/articles/article-factoring-tesuryo/">手数料相場</a>をご確認ください。</p>
