4:T120d,<p>ファクタリングを利用した際、キャッシュフロー計算書(CF計算書)上のどの区分に記載するかは経理担当者を悩ませる論点です。原則『営業活動によるキャッシュフロー』に区分されますが、ケースによっては財務活動 CF として処理することも。本記事で詳細を解説します。</p>
<hr>
<h2>ファクタリングの CF 区分: 原則「営業 CF」</h2>
<p><strong>基本ルール:</strong> ファクタリングによる入金 = 売掛金回収の前倒し = 営業活動 CF</p>
<p><strong>根拠:</strong></p>
<ul>
<li>売掛金は本業から発生する資産</li>
<li>売掛金の現金化は本業の収入(の前倒し)</li>
<li>CF 計算書原則: 売掛金の増減は営業 CF 区分</li>
</ul>
<h2>間接法での記載方法</h2>
<p><strong>間接法 CF 計算書:</strong></p>
<pre><code>営業活動によるキャッシュフロー
  税引前当期純利益               XXX
  売上債権売却損(調整不要)        +5万
  売掛金の減少                  +100万
  ...
</code></pre>
<p><strong>ポイント:</strong></p>
<ul>
<li>売掛金の減少は営業 CF プラス計上</li>
<li>売上債権売却損は『非資金費用』ではないので調整不要</li>
<li>結果として営業 CF は +95 万円(実入金額と一致)</li>
</ul>
<h2>直接法での記載方法</h2>
<p><strong>直接法 CF 計算書:</strong></p>
<pre><code>営業活動によるキャッシュフロー
  営業収入(売掛金回収を含む)      +95万
  営業支出                       -XXX
  ...
</code></pre>
<p><strong>ポイント:</strong></p>
<ul>
<li>売掛金売却による入金 95 万円を『営業収入』として計上</li>
<li>売却損 5 万円は計上不要(差引後の入金が CF)</li>
</ul>
<h2>継続契約・大規模利用時の処理</h2>
<p><strong>継続契約型のファクタリング:</strong></p>
<ul>
<li>売掛金売却の都度、営業 CF として計上</li>
<li>月次集計が一般的</li>
</ul>
<p><strong>大規模利用(年商の 5% 以上):</strong></p>
<ul>
<li>CF 計算書の注記に重要なファクタリング取引として記載推奨</li>
<li>投資家・銀行への説明資料として活用</li>
</ul>
<p><strong>特殊ケース(ノンリコース vs リコース):</strong></p>
<ul>
<li>ノンリコース(償還義務なし): 通常の営業 CF</li>
<li>リコース(償還義務あり): 借入金的性質、財務 CF として処理する見解もあり</li>
</ul>
<h2>CF 計算書全体への影響</h2>
<p><strong>営業 CF の変動:</strong></p>
<ul>
<li>売掛金の減少 = 営業 CF プラス</li>
<li>ファクタリングを多用すると営業 CF が大きく見える錯視あり</li>
</ul>
<p><strong>投資家・銀行の視点:</strong></p>
<ul>
<li>営業 CF の質を見抜くため、ファクタリング比率は注目される</li>
<li>過度な依存は警戒される(継続的に売掛金が手元にない状態)</li>
</ul>
<hr>
<h2>よくある質問</h2>
<p><strong>Q: ファクタリングは営業 CF か財務 CF か？</strong>
A: 原則として営業 CF。売掛金の前倒し回収という性格上、本業のキャッシュ動向として処理。</p>
<p><strong>Q: ノンリコースとリコースで CF 区分は変わる？</strong>
A: 通常はどちらも営業 CF。ただしリコース(償還義務付)を実質的に借入金として処理する場合は財務 CF とする見解あり。</p>
<p><strong>Q: 間接法と直接法のどちらが推奨？</strong>
A: 中小企業は間接法が一般的。大企業や上場企業は直接法も併用。</p>
<p><strong>Q: CF 計算書の注記にファクタリングを記載すべき？</strong>
A: 重要性の高い取引(年商の 5% 以上等)は注記推奨。透明性確保のため。</p>
<p><strong>Q: ファクタリング多用で営業 CF が大きく見える対策は？</strong>
A: 売掛金回転日数を併記し、ファクタリングなしでの本業 CF も推計できるようにする。</p>
<p><strong>Q: 税理士と意見が分かれる時はどう対応？</strong>
A: 重要性の判断はケースバイケースのため、税理士・公認会計士と相談の上、社内ルールを決定。</p>
