4:T371f,<p>翌月の支払いに資金が足りるかどうかは、多くの事業者にとって重要な関心事です。</p>
<p>この不安を解消するのが、<strong>資金繰り表</strong>です。個人事業主であっても、資金の流れを可視化することで、資金不足のリスクを事前に把握し、適切な対策を講じることができます。</p>
<p>この記事では、資金繰り表の基本、Excelで作成できる5つのステップ、資金繰りを改善するポイントを解説します。</p>
<hr>
<h2>資金繰り表の概要</h2>
<p>資金繰り表とは、<strong>一定期間の現金の入出金を予測・管理するための表</strong>です。損益計算書が「利益」を管理するのに対し、資金繰り表は「現金（キャッシュ）」を管理します。</p>
<h3>損益計算書との違い</h3>
<table>
<thead>
<tr>
<th>項目</th>
<th>損益計算書</th>
<th>資金繰り表</th>
</tr>
</thead>
<tbody>
<tr>
<td>管理対象</td>
<td>利益（売上−経費）</td>
<td>現金（入金−出金）</td>
</tr>
<tr>
<td>計上タイミング</td>
<td>発生主義（取引発生時）</td>
<td>現金主義（入出金時）</td>
</tr>
<tr>
<td>減価償却費</td>
<td>経費に含む</td>
<td>含まない（現金流出なし）</td>
</tr>
<tr>
<td>掛取引</td>
<td>売上計上済みでも未入金あり</td>
<td>実際の入金タイミングで記録</td>
</tr>
<tr>
<td>目的</td>
<td>経営成績の把握</td>
<td>資金不足の防止</td>
</tr>
</tbody>
</table>
<p><strong>重要:</strong> 利益が出ていても現金が不足する「黒字倒産」は、資金繰り表を作成していない個人事業主に起こりやすい問題です。売上が増えるほど仕入れ・外注費も増え、入金よりも出金が先行する構造になりやすいためです。</p>
<hr>
<h2>資金繰り表を作成する5つのステップ</h2>
<h3>ステップ1: テンプレートを用意する</h3>
<p>ExcelまたはGoogleスプレッドシートで、横軸（月）と縦軸（項目）を設定し、以下の表を作成します。</p>
<p><strong>基本レイアウト:</strong></p>
<pre><code>              | 4月  | 5月  | 6月  | 7月  | 8月  | 9月  |
─────────────┼─────┼─────┼─────┼─────┼─────┼─────┤
【前月繰越残高】 |      |      |      |      |      |      |
─────────────┼─────┼─────┼─────┼─────┼─────┼─────┤
【収入の部】    |      |      |      |      |      |      |
 現金売上      |      |      |      |      |      |      |
 売掛金回収    |      |      |      |      |      |      |
 その他収入    |      |      |      |      |      |      |
 収入合計      |      |      |      |      |      |      |
─────────────┼─────┼─────┼─────┼─────┼─────┼─────┤
【支出の部】    |      |      |      |      |      |      |
 仕入れ       |      |      |      |      |      |      |
 外注費       |      |      |      |      |      |      |
 人件費       |      |      |      |      |      |      |
 家賃        |      |      |      |      |      |      |
 光熱費・通信費 |      |      |      |      |      |      |
 借入金返済    |      |      |      |      |      |      |
 税金・保険料   |      |      |      |      |      |      |
 その他支出    |      |      |      |      |      |      |
 支出合計      |      |      |      |      |      |      |
─────────────┼─────┼─────┼─────┼─────┼─────┼─────┤
【収支差額】    |      |      |      |      |      |      |
【翌月繰越残高】 |      |      |      |      |      |      |
</code></pre>
<h3>ステップ2: 前月繰越残高を記入する</h3>
<p>事業用口座の残高と手元現金の合計を、「前月繰越残高」に記入します。<strong>事業用口座の実際の残高と一致させてください。</strong></p>
<h3>ステップ3: 収入を予測して記入する</h3>
<p>各月の収入を「入金されるタイミング」で記入します。</p>
<p>記入の際は、次の点にご注意ください。</p>
<ul>
<li>売掛金は「売上計上月」ではなく「入金予定月」に記入する</li>
<li>新規顧客からの入金は、確実性を考慮して控えめに見積もる</li>
<li>季節変動がある業種は、過去の実績を参考にする</li>
</ul>
<h3>ステップ4: 支出を予測して記入する</h3>
<p>各月の支出を「支払うタイミング」で記入します。</p>
<p><strong>見落としやすい支出:</strong></p>
<ul>
<li>年1回の支払い（確定申告の所得税・住民税・個人事業税）</li>
<li>賞与・ボーナス月の人件費</li>
<li>設備の更新・修繕費</li>
<li>保険料の年払い</li>
<li>消費税の納付（前々年の売上が1,000万円超の場合）</li>
</ul>
<h3>ステップ5: 収支差額と翌月繰越残高を計算する</h3>
<pre><code>収支差額 ＝ 収入合計 − 支出合計
翌月繰越残高 ＝ 前月繰越残高 ＋ 収支差額
</code></pre>
<p><strong>翌月繰越残高がマイナスになる月がある場合は、注意が必要です。</strong> そのままでは資金が不足するため、事前に対策を講じる必要があります。</p>

<hr>
<h2>資金繰り表を活用した5つの改善ポイント</h2>
<h3>1. 入金サイトを短くする</h3>
<p>売掛金の回収を早めることは、資金繰りの改善において最も効果的な方法です。</p>
<ul>
<li>取引先に支払いサイトの短縮を交渉する（月末締め翌々月払い→翌月払い）</li>
<li>早期支払い割引を提案する</li>
<li>ファクタリングで、売掛金を即日資金化する</li>
</ul>
<h3>2. 支払いサイトを長くする</h3>
<p>仕入れ先や外注先への支払いを、可能な範囲で後ろ倒しにします。ただし、<strong>取引先との関係を損なわない範囲で</strong>行うことが重要です。</p>
<h3>3. 固定費を削減する</h3>
<p>毎月の固定費を見直すことで、資金繰りは大幅に改善します。</p>
<table>
<thead>
<tr>
<th>見直し項目</th>
<th>具体的な対応</th>
<th>月間削減額の目安</th>
</tr>
</thead>
<tbody>
<tr>
<td>家賃</td>
<td>コワーキングスペースの活用、移転</td>
<td>3〜10万円</td>
</tr>
<tr>
<td>通信費</td>
<td>プランの見直し、格安SIMの利用</td>
<td>0.5〜2万円</td>
</tr>
<tr>
<td>サブスクリプション</td>
<td>不要なサービスの解約</td>
<td>1〜5万円</td>
</tr>
<tr>
<td>保険料</td>
<td>補償内容の見直し</td>
<td>0.5〜2万円</td>
</tr>

<h3>4. 繁忙期・閑散期に備える</h3>
<p>季節変動がある業種では、<strong>繁忙期の利益を閑散期の資金に充てる</strong>計画を立ててください。資金繰り表で年間の変動を可視化することで、「いつ、いくら準備しておくべきか」が明確になります。</p>
<h3>5. 資金不足の「3か月前」に対策を始める</h3>
<p>資金繰り表でマイナスが見込まれる場合は、<strong>遅くとも3か月前には対策を始めてください。</strong> 融資の申込から入金まで2〜4週間かかるため、直前では間に合いません。</p>
<hr>
<h2>資金繰り表を作成する際によくある誤り</h2>
<h3>誤り1: 売上と入金を混同する</h3>
<p>「今月100万円の仕事を受注した」ことは、「今月100万円が入金される」ことを意味しません。請求書を発行してから実際に入金されるまでの期間（支払いサイト）を、正確に反映させてください。</p>
<h3>誤り2: 楽観的な予測をする</h3>
<p>受注が確定していない見込み客を収入に含めると、計画と実績が乖離します。<strong>確定した案件のみを収入に計上し、見込み案件は別枠で管理する</strong>方法が安全です。</p>
<h3>誤り3: 税金の支払いを見落とす</h3>
<p>所得税、住民税、消費税、個人事業税など、年に1〜4回まとめて支払う税金は、見落としやすい項目です。前年の実績を参考に、資金繰り表に組み込んでください。</p>
<hr>

<h2>まとめ</h2>
<p>資金繰り表は、個人事業主が資金の不安を解消するための、最も基本的な管理表です。</p>
<p><strong>作成の5つのステップ:</strong></p>
<ol>
<li>テンプレートを用意する</li>
<li>前月繰越残高を記入する</li>
<li>収入を「入金タイミング」で予測する</li>
<li>支出を「支払いタイミング」で予測する</li>
<li>収支差額と翌月繰越残高を計算する</li>
</ol>
<p>資金繰りを改善するには、次の方法が有効です。</p>
<ul>
<li>入金サイトを短く、支払いサイトを長くする</li>
<li>固定費を定期的に見直す</li>
<li>マイナスが見込まれる場合は、3か月前に対策を始める</li>
</ul>
<p>資金繰り表を作成していない場合は、まずExcelで簡単なものを作成してください。月に1回更新することで、資金不足のリスクを大幅に減らすことができます。資金調達の全体像については、<a href="/articles/article-kojin-shikin-chotatsu/">個人事業主の資金調達方法10選</a>もあわせてご覧ください。</p>
