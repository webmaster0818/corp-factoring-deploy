4:T1ebf,<p>「でんさいって何？ファクタリングと何が違うの？」——電子記録債権（でんさい）はファクタリングと並んで注目される資金調達ツールです。それぞれの違いを理解して、自社に合った方法を選びましょう。</p>
<hr>
<h2>でんさい（電子記録債権）とは</h2>
<h3>基本概念</h3>
<p>でんさいとは、**電子的に記録・管理される売掛債権（電子記録債権）**の愛称で、「でんさいネット」（全銀電子債権ネットワーク）が運営するシステムで取り扱われます。</p>
<pre><code>【でんさいの特徴】
・紙の手形・受取手形の電子版
・でんさいネットのシステムで管理
・2013年サービス開始
・大手銀行・地方銀行が参加
</code></pre>
<h3>でんさいの仕組み</h3>
<pre><code>【でんさい発生の流れ】
1. 支払企業がでんさいネットに「電子記録債権の発生」を登録
2. 受取企業に通知
3. 受取企業が内容確認・承諾
4. 支払期日に自動で口座振込み
</code></pre>
<hr>
<h2>ファクタリングとでんさいの比較</h2>
<p>| 観点 | ファクタリング | でんさい（でんさい割引） |
|-----|-------------|-----------------|
| <strong>仕組み</strong> | 売掛金を第三者に売却 | 電子記録債権を銀行に割り引いてもらう |
| <strong>対象となる債権</strong> | 一般的な売掛金 | でんさいとして登録された電子記録債権 |
| <strong>利用する機関</strong> | ファクタリング会社 | 銀行（でんさいネット参加行） |
| <strong>コスト</strong> | 手数料3〜20% | 割引料（市場金利＋αで1〜3%程度） |
| <strong>スピード</strong> | 最短即日 | 申込後数日 |
| <strong>審査</strong> | 売掛先重視 | 申込者の信用力も重視 |
| <strong>返済義務</strong> | なし（ノンリコース） | 遡及義務あり（でんさい割引の場合） |
| <strong>取引先の承諾</strong> | 2社間では不要 | でんさい発生時に承諾が必要 |</p>
<hr>
<h2>でんさい割引の仕組み</h2>
<p>でんさいを資金化する方法として「でんさい割引」があります。</p>
<pre><code>【でんさい割引の流れ】
受取企業がでんさいを保有
  ↓
取引銀行に割引申込み
  ↓
銀行が審査・割引料を提示
  ↓
割引後の金額を受取（支払期日前に現金化）
  ↓
支払期日に支払企業→銀行へ入金
</code></pre>
<p><strong>遡及義務（リコース）：</strong>
でんさい割引には遡及義務があり、支払企業が倒産した場合に受取企業が買い戻す義務があります。この点がノンリコースのファクタリングと大きく異なります。</p>
<hr>
<h2>でんさいのメリット・デメリット</h2>
<h3>でんさいのメリット</h3>
<p>| メリット | 内容 |
|---------|-----|
| 低コスト | 割引料が1〜3%程度と安い |
| 紛失・盗難リスクなし | 電子化されているため |
| 分割譲渡が可能 | 1つのでんさいを分割して使える |
| 手形より管理が楽 | 印紙税不要・物理的保管不要 |
| 銀行と連携 | 既存の取引銀行で利用可能 |</p>
<h3>でんさいのデメリット</h3>
<p>| デメリット | 内容 |
|----------|-----|
| 普及率の課題 | でんさいに対応していない企業がある |
| 銀行の審査が必要 | 信用力が低い企業は審査が厳しい |
| 遡及義務 | 支払企業倒産時に買戻しリスク |
| 手続きが煩雑 | でんさいの発生登録・承諾が必要 |
| 対応銀行の制限 | 参加していない金融機関がある |</p>
<hr>
<h2>ファクタリングとでんさいの使い分け</h2>
<h3>ファクタリングを選ぶべき場面</h3>
<ul>
<li>売掛先がでんさいに対応していない</li>
<li>急ぎで今日中に現金が必要（最短即日）</li>
<li>売掛先倒産リスクをゼロにしたい（ノンリコース）</li>
<li>銀行融資枠を使いたくない</li>
</ul>
<h3>でんさいを選ぶべき場面</h3>
<ul>
<li>コストを最低限に抑えたい（1〜3%）</li>
<li>すでにでんさいで取引している取引先がある</li>
<li>分割譲渡が必要</li>
<li>銀行との関係を強化したい</li>
</ul>
<hr>
<h2>でんさいとファクタリングの組み合わせ戦略</h2>
<p>取引先がでんさいを使っている場合でも、ファクタリング会社によってはでんさいを担保・対象としてファクタリングを行えます。</p>
<pre><code>【でんさいのファクタリング活用】
でんさい（電子記録債権）を保有
  ↓
でんさい対応のファクタリング会社に譲渡
  ↓
手数料を支払って即日現金化
（でんさい割引より高い手数料だが即日対応）
</code></pre>
<hr>
<h2>手形・でんさい・ファクタリングの全体比較</h2>
<p>| 項目 | 約束手形 | でんさい | ファクタリング |
|-----|---------|--------|-------------|
| <strong>電子化</strong> | なし | あり | 一部あり |
| <strong>印紙税</strong> | 必要 | 不要 | <a href="/articles/article-factoring-inshizei/">不要</a> |
| <strong>割引コスト</strong> | 低い | 低い | やや高め |
| <strong>現金化スピード</strong> | 数日 | 数日 | 最短即日 |
| <strong>倒産リスク</strong> | 遡及あり | 遡及あり | ノンリコース |
| <strong>普及度</strong> | 減少傾向 | 拡大中 | 拡大中 |</p>
<hr>
<h2>政府・金融庁の方針</h2>
<p>政府は約束手形の2026年廃止を推進しており、でんさいへの移行を促進しています。<a href="/articles/article-factoring-shijou-kibo/">ファクタリング市場規模</a>の拡大もこうした動きと連動しています。</p>
<hr>
<h2>まとめ</h2>
<p>でんさいとファクタリングはどちらも売掛金を前倒しで現金化する手段ですが、コスト・スピード・倒産リスクの扱いで大きな違いがあります。でんさいが使える状況ではコストを抑えられ、緊急性や倒産リスク回避を優先するならファクタリングが適しています。<a href="/articles/article-factoring-shikinguri/">資金繰り改善</a>の全体戦略の中で最適な組み合わせを検討してください。</p>
<hr>
<h2>よくある質問（FAQ）</h2>
<p><strong>Q: でんさいとファクタリング、どちらが安いですか？</strong>
A: でんさい割引の方がコスト（割引料1〜3%）が安いのが一般的です。ただしでんさいに対応していない取引先には使えません。</p>
<p><strong>Q: でんさいを使っている場合、ファクタリングは使えませんか？</strong>
A: でんさいでも対応するファクタリング会社があります。ただしでんさい割引より手数料が高くなることが多いです。</p>
<p><strong>Q: 手形からでんさいに切り替えるのは難しいですか？</strong>
A: でんさいネットに参加している取引銀行があれば、手続き自体は難しくありません。ただし取引先もでんさいに対応している必要があります。</p>
<p><strong>Q: 2026年に手形が廃止されたらどうなりますか？</strong>
A: 約束手形の廃止はでんさいへの移行を意味します。ファクタリングも引き続き利用可能です。</p>
<p><strong>Q: でんさいの遡及義務（買戻し義務）はどう対処すればいいですか？</strong>
A: 取引先の信用力を定期的にチェックし、リスクが高いと感じたらでんさいをファクタリングで売却（ノンリコース化）することも選択肢です。</p>
